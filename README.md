# DocDD Console

Браузерный инструмент контроля разработки: показывает, в каком состоянии работа
по проекту, и не даёт начать задачу раньше, чем подтверждены её документы.

Работает с любым проектом, который ведёт процесс по контракту
`docdd.workspace/1`: пользователь указывает корень проекта, приложение читает
папку `docs/development` и строит по ней граф требований, документов, задач и
проверок.

> **Как этим воспользоваться.** Эта папка — заготовка отдельного репозитория.
> Скопируйте её содержимое в корень нового пустого репозитория: `README.md` и
> `CLAUDE.md` лягут в корень, `docs/` — рядом. После этого начинайте работу в
> новой сессии: первым делом читается `CLAUDE.md`, дальше `docs/00-overview.md`.
> Кода в заготовке нет намеренно — по правилу DocDD он пишется после того, как
> документы подтверждены.

## Стек

Nuxt 4 (TypeScript), серверная часть Nitro для доступа к файлам, Ajv для
проверки схем, `gray-matter` и `js-yaml` для разбора файлов, mermaid для
диаграмм. Базы данных нет: источником правды остаются файлы проекта.

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на `http://localhost:3000` и работает только на машине
пользователя: наружу серверная часть не смотрит.
