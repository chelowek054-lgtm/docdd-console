# DocDD Console — инструкции для Codex

DocDD Console читает `docs/development` выбранного проекта, строит граф работы и
проверяет готовность задач к запуску. Общие правила репозитория находятся в
[CLAUDE.md](CLAUDE.md). Прочитай его при входе в
репозиторий и применяй общие правила в задачах Codex.

## Перед началом

1. Проверь текущую ветку, состояние рабочего дерева и последние коммиты.
   Сохрани уже имеющиеся пользовательские изменения.
2. Сверь поручение с [контрактом рабочего пространства](docs/02-workspace-contract.md),
   [порядком фаз](docs/06-phases.md) и соответствующими записями
   `docs/development`. Определяй актуальное состояние по коммитам, записям
   задач и результатам проверок.
3. Перед новой функцией или рефакторингом прочитай
   [индекс переиспользования](docs/development/reference/INDEX.md).

## Как проводить изменения

- Для изменения поведения сначала зафиксируй его в документах и получи явное
  подтверждение человека перед правкой кода. Для новой функции начни с функциональной
  карты и свяжи требование, проверку, задачу и затронутые карты. У задачи должен
  быть раздел «Ожидаемый результат». Исключения описаны в [CLAUDE.md](CLAUDE.md).
- При исполнении задачи через консоль соблюдай ограничения на изменение записей
  процесса. Для MCP применяй правила доступа и подтверждения из
  [руководства MCP](docs/17-mcp.md). Факт реализации устанавливай по коду, факт
  прохождения проверки по её результату, факт приёмки по записи в DocDD.
- Новые серверные возможности оформляй модулем с публичным `index.ts`.
  Следуй [архитектуре проекта](docs/18-architecture.md). Клиент обращается к
  файловым данным через API. При записи сохраняй незнакомые поля документов.

## Проверки

Для изменений кода запускай `npm run typecheck`, `npm run test`,
`npm run lint` и `npm run check -- .`. Если PowerShell блокирует `npm.ps1`,
используй `npm.cmd`. При изменении привязанных к коду строк сверяй свидетельства
карт с `tests/self-map.spec.ts`. Для передачи работы укажи, какие проверки
действительно прошли и какая приёмка ещё нужна.
