## Правила репозитория (коротко)
- Документ ведёт код: правка документа → подтверждение → код → сверка.
- Документы и код — разными коммитами.
- Слияние только по просьбе «слей в main», через PR:
  1. `gh pr create --body-file`;
  2. `gh pr merge --merge`;
  3. удалить ветку локально и на сервере;
  4. `git switch main; git pull --ff-only`.
- Подпись коммита: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Не коммитить `.data/`, `.env`, ключи.
