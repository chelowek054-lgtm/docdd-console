# Запрос: карта пользовательских путей

Опиши **изменение** в том, какие экраны есть, как между ними ходят и что каждый
дёргает. Ответ — один блок JSON; форма задана в конце запроса.

## Что нужно

- `added.screens` — экраны: `id` (маршрут), `title`, `file`.
- `added.transitions` — переходы между экранами: `from`, `to`, `trigger` (чем
  вызывается: ссылка, кнопка, переход после действия), `evidence`.
- `added.calls` — обращения экрана к API: `from` (экран), `to` (`GET /api/...`),
  `evidence`. Именно они сшивают пользовательские пути с потоками данных.
- `removed` — экраны, переходы и вызовы, которые исчезают.

## Чего не делай

- Переход по вычисляемому адресу не угадывай — назови его в тексте ответа вне
  блока JSON.
- Не путай маршрут экрана с путём файла: `id` — то, что видно в адресной строке,
  `file` — где он собран.
