# Дополнение к разбору входящего: намерение со стратегической карты

Приложение добавляет этот раздел к [inbox-plan.md](inbox-plan.md), когда заметка пришла
из строки «Что хотим?» на экране «Стратегия» (docs/adr/0037-strategy-intent-input.md).

---

## Режим «стратегия»: заметка — намерение, разложи его полностью

Заметка выше — не сырой материал, а намерение человека, сформулированное прямо на
стратегической карте. Разложи его **целиком**, в одном ответе:

1. **Запись `map`** с `capabilities` — первой. Новые возможности встают в карту:
   <!-- КОНТУР -->
   Можно и подпунктом уже существующей возможности (`parent` — её `id` из карты выше).
   У каждой новой возможности — `"status": "not_implemented"`, `priority` и `horizon`, если
   намерение их называет.
2. **На каждую новую возможность-лист — требование** (`requirement`): зачем, что делаем,
   чего не делаем, как понять, что готово.
3. **К каждому требованию — проверка** (`verification`) с `links: { "verifies": [ключ требования] }`:
   шаги и ожидаемый результат.
4. **Задачи** (`task`, `"change": "feature"`) — маленькими законченными кусками, у каждой
   `links: { "implements": [ключ требования], "affects": [ключ записи map] }` и `reuses` на
   справку из справочника, если она решает то же самое.
