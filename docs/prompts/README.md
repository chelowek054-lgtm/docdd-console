# Шаблоны запросов к модели

Приложение собирает запрос по этим шаблонам — подставляет список нарушений,
состояние карт, задачу со связями — и отправляет его модели через Claude Code на
машине пользователя ([adr/0008-llm-through-claude-code.md](../adr/0008-llm-through-claude-code.md)).
Ответ ничего не меняет сам: его разбирает и подтверждает человек. Claude Code не
найден — кнопка «Спросить модель» неактивна и называет причину, а «Скопировать
запрос» работает всегда: текст можно отнести в своё окно, как раньше.

Шаблоны лежат в репозитории и правятся как всё остальное: качество карты — это
качество запроса, и спорить о нём нужно в дифф, а не в переписке.

Общее правило для трёх шаблонов карт (`codemap`, `dataflow`, `userflow`): **каждое ребро несёт свидетельство** — путь, строку
и фрагмент. Утверждение без свидетельства приложение отвергнет, и это не
придирка: непроверяемая карта — красивая ложь через месяц.

## Шаблоны ролей

Шаблоны `roles/*.md` объявляют нужды пакета контекста ([../adr/0021-context-pack.md](../adr/0021-context-pack.md)) и получают его вместо маркера `<!-- КОНТЕКСТ -->`; вопрос человека встаёт на место `<!-- ВОПРОС -->`. Ответ — черновик заметки.

| Шаблон | Роль | Что просит |
|---|---|---|
| [roles/manager.md](roles/manager.md) | Менеджер | Ход работы, блокеры, план фазы |
| [roles/analyst.md](roles/analyst.md) | Аналитик | Уточнения, противоречия, критерии готовности |
| [roles/domain.md](roles/domain.md) | Доменный специалист | Проверка терминов и допущений |
| [roles/observer.md](roles/observer.md) | Наблюдатель | Пересказ простыми словами, без правок |

| [as-is.md](as-is.md) | Возможности и требования «как есть» для готовой кодовой базы, со свидетельством `путь:строка` | Вкладка «Подключение»: «Восстановить как есть» |
