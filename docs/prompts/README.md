# Шаблоны запросов к модели

Приложение к языковым моделям не обращается ([adr/0003-no-llm-in-app.md](../adr/0003-no-llm-in-app.md)).
Запрос составляет человек — сам или своим агентом — по этим шаблонам. Часть из
них приложение готовит за вас: подставляет список нарушений или состояние карт и
кладёт готовый текст в буфер обмена. Дальше вы решаете, что с ним делать.

Шаблоны лежат в репозитории и правятся как всё остальное: качество карты — это
качество запроса, и спорить о нём нужно в дифф, а не в переписке.

| Шаблон | Что просит | Откуда вызывается |
|---|---|---|
| [codemap.md](codemap.md) | Модули и импорты | Вручную |
| [dataflow.md](dataflow.md) | Источники данных и потоки к ним | Вручную |
| [userflow.md](userflow.md) | Экраны, переходы и вызовы API | Вручную |
| [update-maps.md](update-maps.md) | Построить или обновить все три карты | Кнопка «Обновить карты» |
| [fix-plan.md](fix-plan.md) | План починки нарушений | Кнопка «Исправить» |
| [fix-apply.md](fix-apply.md) | Починка по подтверждённому плану | Кнопка «Принять ответ» |
| [fix-map-answer.md](fix-map-answer.md) | Поправить ответ, не прошедший схему | Кнопка «Попросить поправить» |

Два последних приложение подставляет данными и копирует в буфер. Отправить
запрос оно не может и не будет: показать текст — это не то же самое, что
обратиться к модели.

Общее правило для всех трёх: **каждое ребро несёт свидетельство** — путь, строку
и фрагмент. Утверждение без свидетельства приложение отвергнет, и это не
придирка: непроверяемая карта — красивая ложь через месяц.
