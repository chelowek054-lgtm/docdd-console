# Запрос: расставить фазы и задачи по важности

Приложение подставляет сюда вектор продукта и фазы с их задачами. Ответ ничего не
меняет сам: человек читает таблицу порядка, и только его «Применить порядок» записывает
`rank` у фаз и порядок `covers` ([04-ui.md](../04-ui.md), «Порядок по важности»).

---

Ты расставляешь работу по важности: в первую очередь **фазы**, а внутри каждой фазы —
**задачи**. Инструментов у тебя нет, и они не нужны: всё, что нужно, — в списке ниже, кратко.
Суди по названиям и связям; в репозиторий не ходи.

**Отвечай за один ход и сам.** Не запускай помощников и фоновые задачи и не обещай
вернуться позже.

## Как решать, что важнее

1. **Блокеры — раньше.** Если без одной задачи другую не начать (`зависит от`), или задача
   упирается в неподтверждённое (`мешает`) и разблокирует других, она идёт раньше.
   Порядок `зависит от` — жёсткое условие: приложение всё равно не позволит зависимой
   задаче встать перед той, от которой она зависит.
2. **Концептуально важное — раньше.** Основание перед надстройкой: то, на чём стоит
   остальное (модель данных, граница модулей, безопасность), идёт перед тем, что на нём
   строится, даже если формального блокера нет.
3. **Служит ли вектору.** Что прямо отвечает на проблему, ради которой делается продукт,
   — выше того, что второстепенно.
4. **Закрытое и отменённое** в список не вошло: оно встанет в конец само.

## Что от тебя нужно

Один блок JSON: все фазы по важности, в каждой — все её задачи по важности. У каждой фазы и
задачи — одна короткая фраза `why`: почему она стоит именно здесь. Номера — ровно как в
списке выше; чужих не придумывай. `why` — до десяти слов и только у фаз и задач-блокеров;
у остальных задач оставь пустую строку.

````
```docdd-order
{
  "phases": [
    {
      "id": "P-0003",
      "why": "модель данных — основание для всего остального",
      "tasks": [
        { "id": "T-0010", "why": "блокирует T-0011 и T-0012" },
        { "id": "T-0011", "why": "" }
      ]
    }
  ]
}
```
````

Перед блоком можно написать пару строк — что показалось неочевидным; после блока ничего не
нужно.
