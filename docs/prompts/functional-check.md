# Запрос: сверить функциональную карту с кодом

Приложение подставляет сюда дерево возможностей функциональной карты вместе с
текущим состоянием реализации. Ответ ничего не меняет сам и ничего не
подтверждает: у этого вида карты нет свидетельства, и ответ модели им не
становится — человек читает предложение, правит его и сохраняет отметками, а
потом подтверждает черновик карты (docs/07-maps.md, «Ответ „Проверить по коду“»).

---

Функциональная карта описывает, что система умеет, на языке предметной
области — не код, не файлы. Ниже — её текущее дерево. Код читай сам —
доступ на чтение у тебя есть, рабочая папка уже корень проекта. Ничего не
меняй: `Edit`/`Write` тебе недоступны, это разовая проверка, а не задача.

## Функциональная карта

Рядом с каждой возможностью — её отметка сейчас: `implemented`, `partial`,
`not_implemented` или «не оценено».

## Что от тебя нужно

Оцени **только нижние** возможности — те, у которых нет подпунктов: состояние
родителя приложение посчитает само. По каждой реши, что из описанного
(`title` и описание) в коде уже работает:

- `implemented` — **всё** описанное есть и подключено, а не лежит заготовкой.
- `partial` — часть есть, части нет. Обязательно напиши в `note`, чего именно
  не хватает.
- `not_implemented` — следов реализации не нашёл.

Если не можешь решить, **не включай возможность в ответ** вовсе: пропуск
честнее уверенного ответа наугад. Приложение оставит ей прежнюю отметку. «Не
нашёл — возможно, названо в коде иначе» — это пропуск, а не `not_implemented`.

`note` — одна-две фразы простыми словами (карту читают не только разработчики):
что нашёл и чего нет. Файл или модуль можно назвать, номера строк — нет.

Формат — один блок JSON, без текста внутри:

````
```docdd-functional-check
{
  "checks": [
    { "id": "orders.pay", "status": "partial", "note": "Карты принимаются, возвратов и частичной оплаты нет" },
    { "id": "orders.cancel", "status": "not_implemented", "note": "Кнопки и обработчика отмены в коде нет" }
  ]
}
```
````

`id` — ровно как в карте выше. Перед блоком можно написать пару строк — что
показалось неочевидным; после блока ничего не нужно.
