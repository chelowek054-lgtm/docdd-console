# Запрос: построить или обновить карты проекта

Приложение подставляет сюда состояние карт и список того, что перестало
сходиться. Ответ сохраняется **черновиком** записи типа `map` и требует
подтверждения человеком ([07-maps.md](../07-maps.md)).

---

Тебе нужно описать устройство проекта в трёх структурах: кодовая база, потоки
данных, пользовательские пути.

Форма блоков задана ниже целиком — искать её в файлах проекта не нужно и негде:
схемы живут в инструменте, а не в разбираемом проекте.

<!-- СОСТОЯНИЕ -->

## Что от тебя нужно

Разбери файлы проекта и верни **три блока** ровно в таком виде:

```docdd-codemap
{ "added": { "modules": [...], "imports": [...] }, "removed": { ... } }
```

```docdd-dataflow
{ "added": { "sources": [...], "flows": [...] } }
```

```docdd-userflow
{ "added": { "screens": [...], "transitions": [...], "calls": [...] } }
```

```docdd-skipped
{ "files": [{ "path": "app/src/main/res/values/colors.xml", "why": "ресурс, не модуль" }] }
```

## Файл, которому не место в карте

Картинка, файл ресурсов, тема, заготовка теста — не модули, и выдумывать им
место в карте не надо. **Но и молчать о них нельзя:** файл, о котором ты не
сказал ничего, вернётся в этот запрос и в следующий раз, и так без конца.

Поэтому каждый названный выше файл должен попасть либо в карту, либо в блок
`docdd-skipped` — с причиной в одну строку. Причина нужна человеку, который
будет читать карту через полгода: «ресурс, не модуль», «заготовка теста»,
«иконка приложения».

<!-- СХЕМЫ -->

## Свидетельство обязательно

У каждого импорта, потока, перехода и вызова:

```json
{ "path": "server/lib/cache.ts", "line": 34, "fragment": "writeFileSync(path" }
```

Путь от корня проекта через прямой слеш, номер строки с единицы, фрагмент —
кусок именно этой строки. Приложение сверит каждое свидетельство с настоящим
файлом; утверждение без свидетельства оно отвергнет.

## Границы

- **Называй убранное, а не только добавленное.** Карта, которая только растёт,
  через полгода перестаёт быть правдой.
- **Не угадывай.** Чего не понял — перечисли текстом вне блоков JSON.
- Внешние пакеты модулями не считаются: карта про устройство проекта, а не про
  его зависимости.
- Метрик качества не надо: ни техдолга, ни дублирования, ни уязвимостей.
