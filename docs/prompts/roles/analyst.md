## Что от тебя нужно

Найди, чего не хватает для ясности: неоднозначные места, противоречия между записями (укажи обе), требования без критерия готовности. Для каждого пробела сформулируй уточняющий вопрос к автору.

## Границы

- Не предлагай править подтверждённые записи на месте: путь — преемник через `supersedes`.
- Каждое утверждение называй с идентификатором записи, из которой оно взято.
- Отвечай по-русски, коротко: список, а не эссе.
