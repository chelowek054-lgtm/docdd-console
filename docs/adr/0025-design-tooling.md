# ADR-0025. Инструменты вокруг токенов: конструктор тем, режимы, конструкторы, Figma, версии, i18n консоли

- Статус: принято · 2026-10-12
- Дата: 2026-10-12

## Задача

[ADR-0024](0024-design-from-practice.md) вынес шесть шагов за формат в очередь: конструктор
тем, режимы «дизайнер»/«разработчик», конструкторы форм и таблиц, импорт из Figma,
версии токенов, и отдельным пунктом — консоль, которая сама обязана жить по своим
токенам (rem, сетка, i18n). Этот ADR закрывает очередь и называет границы каждого.

## Решение

1. **Версия токенов — поле блока `version` (`MAJOR.MINOR.PATCH`) и список `changes`.**
   Действует наибольшая из названных версий; список изменений копится и сортируется от
   новых к старым. Версия стоит в шапке каждого файла выгрузки (`токенов дизайна v1.2.1`):
   по ней сверка видит, на какой версии отстал файл проекта, и называет изменения
   между версиями. Номера не вычисляются — их ставит человек, подтверждая запись: машина
   не знает, что считать «мажорным» изменением дизайна. Нет версии — `design_scale_gap`.
2. **Конструктор тем — экран, а не новый тип записи.** Выбор базы и ролей с пересчётом
   контраста по тем же правилам, что у проверки токенов (`paletteContrast` — одна
   функция на экран и на нарушение). Итог — блок `docdd-design` и **черновик записи
   `design`**; тема вступает в силу, когда человек подтвердит запись. Конструктор не
   записывает в токены сам.
3. **Режимы — вид экрана, а не права.** «Дизайнер» прячет инженерное (выгрузка в стеки,
   конструкторы, импорт, имена переменных), «разработчик» показывает; выбор помнит
   браузер. Это не разграничение доступа: роли и права — отдельное решение
   ([ADR-0020](0020-people-roles-permissions.md)).
4. **Конструкторы форм и таблиц — генераторы текста** для четырёх стеков вместе с
   заготовкой словаря на каждый язык проекта. Английский заполняется подсказкой, прочие
   языки пусты: перевод — работа людей, а не догадка машины. Имена идут в код, поэтому
   принимаются только безопасные идентификаторы. Файлы приложение не пишет.
5. **Импорт из Figma — разбор ответа `variables/local`, а не интеграция с Figma.**
   Консоль не ходит в Figma сама и не хранит токен доступа: человек вставляет JSON.
   Имена читаются по пути (`palette/accent`, `spacing/md`, `typography/body/size`),
   режимы `Light`/`Dark` дают базовые темы, прочие — добавленные; px переводятся в rem
   по `root`. Неопознанное **называется**, а не теряется; итог — блок и расхождения
   с токенами проекта, принятие — черновиком записи.
6. **Название темы может быть словарём по языкам** (`label: { ru, en }`): тема в
   эталоне не должна показываться на одном языке в двуязычном интерфейсе.
7. **Консоль принимает собственные токены.** Файлы темы консоли
   (`app/assets/css/main.css` в блоке между метками и `app/design-tokens.ts`) — выгрузка
   тех же токенов, что она спускает в проекты; её заголовок — контейнер общей сетки; её
   языки — те самые `i18n.locales` из токенов, а не отдельный список.
8. **Интерфейс консоли — по ключам словаря.** Инфраструктура (`useT`, словари `ru`, `en`,
   язык в cookie, `lang` страницы) и переведены оболочка, главная, подписи типов,
   статусов и результатов и все экраны «Дизайн». Остальные экраны остаются на русском
   исходнике, пока не переведены на ключи: ключ, которого нет в словаре языка, берётся у
   запасного, затем у основного. Перевод идёт по группам экранов отдельными задачами.

## Что отвергнуто

- **Версия из git или из счёта изменений.** Файлы — источник правды, а не история
  репозитория; версию, которую нельзя прочитать из самой записи, нельзя и сверить на
  сервере, где репозитория может не быть.
- **Интеграция с Figma по токену доступа.** Консоль на общем сервере хранила бы
  секрет доступа к чужому сервису ради операции, которая делается раз в итерацию.
- **Режимы как роли.** Разграничение «дизайнер не видит выгрузку» — не доступ, а удобство:
  запретить было бы нечему, ведь всё это видно из токенов.
- **Подключить готовую i18n-библиотеку сейчас.** `@nuxtjs/i18n` — зависимость и своя
  конфигурация маршрутов ради двух словарей и переключателя; своя прослойка в сорок строк
  не мешает перейти на неё позже: ключи те же.
- **Перевести весь интерфейс одним коммитом.** Около двух тысяч строк в девяноста
  файлах без тестов — риск сломать экраны молча; группами их переводят безопаснее.
