# ADR-0002. Доступ к файлам — через серверную часть Nitro

**Статус:** принят · 2026-08-30

## Контекст

Приложение браузерное, а данные лежат на диске. Способов три: File System Access
API прямо в браузере, отдельный локальный сервис, серверная часть самого Nuxt.

## Решение

Файлы читает и пишет Nitro — серверная часть Nuxt, запущенная на машине
пользователя. Браузер обращается только к её API и о путях ничего не знает.

Сервер работает исключительно внутри объявленного корня проекта: путь
нормализуется, проверяется на принадлежность корню, символические ссылки наружу
не разворачиваются. Слушает только `localhost`, аутентификации нет за
отсутствием удалённого доступа.

## Последствия

- Один процесс на всё: `npm run dev` — и инструмент работает.
- Ядро (разбор, проверка, правила) живёт на сервере и тестируется без браузера.
- Приложение нельзя открыть «просто как страницу» — нужен запуск. Это цена,
  которую платим за доступ к файлам.
- Публиковать такой сервер в сеть нельзя без переработки прав. Об этом сказано
  прямо, чтобы никто не попробовал.

## Отвергнуто

**File System Access API.** Работает не во всех браузерах, требует выдачи прав
на папку при каждом запуске и не даёт нормально обходить дерево.

**Отдельный локальный сервис.** Второй процесс, второй язык, второй способ
запуска — ради того же самого.
