# ADR-0036. Удаление рабочей карты

- Статус: принято · 2026-10-23
- Дата: 2026-10-23
- Дополняет: [ADR-0035](0035-two-kinds-of-maps.md), [ADR-0028](0028-custom-maps.md)

## Задача

Рабочую карту (шаблон с движком или свою) можно завести, но нельзя убрать. Убирать должен не
любой участник, а тот, кто её завёл, или администратор; ошибочное или несанкционированное
удаление должно возвращаться из git.

## Решение

1. **Кто завёл — в определении.** При создании карты в строку `maps.custom` пишется `by` —
   логин создателя. У строк без `by` (заведённых раньше или руками) создателя нет: удалить их
   может только администратор.
2. **Удалить может** создатель (`by` совпадает с логином) или администратор. Остальным кнопки
   нет, сервер отвечает `403 forbidden`. Стратегическую карту удалить нельзя — у неё нет строки
   в `maps.custom`.
3. **Что удаляется — только строка определения** в `project.yaml`, точечно, остальной файл и
   комментарии целы. Записи `map` с содержанием карты не трогаются: подтверждённые записи не
   переписываются, а без определения их блоки просто не показываются. Удаление обратимо.
4. **Восстановление.** Строка удаления — обычная правка файла проекта: она видна в `git diff`
   и возвращается `git checkout`/`git revert` строки `project.yaml`. Шаблон с движком можно и
   завести заново кнопкой «Новая карта» — содержание из записей вернётся само. На экране после
   удаления — подсказка: что удалено, кем и как вернуть.
5. **Старые проекты.** Правило ADR-0035, п. 4 (карта с движком видна по одним записям)
   действует, только пока в манифесте нет списка `maps.custom` вовсе. Иначе удалённая
   кодовая база тут же вернулась бы сама.
6. **Экран.** У открытой рабочей карты — кнопка «Удалить карту» (видна создателю и
   администратору) с подтверждением: название карты, «записи карты останутся, строку можно
   вернуть из git». Маршрут: `DELETE /api/projects/:id/maps/custom/:mapId`.

## Последствия

Убрать карту может её автор или администратор; файлы процесса не теряются, история удаления —
в git. Право `edit_draft` (ADR-0020) по-прежнему нужно и для создания, и для удаления.
