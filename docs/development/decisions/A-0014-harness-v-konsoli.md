# Харнесс в консоли: запуск задачи моделью, живой вывод, лента вопросов

Модели и агенты в настройках никак не используются: человек работает через чат. Чтобы вести проект в консоли было удобнее, чем в чате, нужен полноценный харнесс.

## Решения

1. **Два пути с общим журналом.** Сначала — чат через MCP (A-0008). Потом — харнесс в консоли.
2. **«Запустить» на задаче** поднимает Claude Code CLI в рабочем дереве задачи (ADR-0009). Живой вывод, «Остановить», итог — на проверку. Сессия — одна на задачу.
3. **Лента вопросов** от всех запусков в одном месте; ответ — кнопкой или текстом.
4. **Экран запусков:** состояние, стоимость в токенах, субагенты вложенными строками.
5. Другие модели — через адаптеры ADR-0019.
6. **Роли:** новая роль кнопкой «+» в настройках — имя, права по разделам, агент роли.

## Отвергнуто

- Только чат: без харнесса консоль остаётся местом, куда не заходят.
