# Инструменты: без помощника аналитика; практики обязательны; дизайн-система — записью

## Решения

1. **Помощник аналитика убирается.** Смысловой поиск (ADR-0031) решает то же.
2. **«Инструменты» — две вкладки:** «Практики» и «Дизайн».
3. **Практики — стандарт кода, а не каталог.** Выбор практик — шаг создания и подключения (по профилю и языкам, лишнее снимается). Экран — «включено в проекте» с тем, что каждая проверяет, и числом нарушений; каталог отдельно. Ссылка из раздела «Стандарты» System Design.
4. **Дизайн-система — запись** с разделами: токены, единицы и почему (rem), типографика, шрифты и лицензии, анимации, сетка и раскладка, принципы UX и UI. Заполняется на допросе нового проекта, читается любой моделью через MCP. Токены ADR-0022 — её часть.

## Отвергнуто

- Оставить практики в глубине «Инструментов»: в них не заходят даже при создании проекта.
