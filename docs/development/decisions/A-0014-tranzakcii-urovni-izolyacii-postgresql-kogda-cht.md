# Транзакции: уровни изоляции PostgreSQL — когда что использовать

Read Committed (умолчание) — для простых операций с заранее известными строками. Repeatable Read — когда транзакции нужен согласованный снимок на всё время жизни. Serializable — когда логическая согласованность важнее параллелизма: PostgreSQL сам ловит конфликты, которых Repeatable Read не видит. Ошибку сериализации (SQLSTATE 40001) всегда перезапускать транзакцию целиком — ожидаемый исход, не авария. Транзакции держать короткими. Читающую-без-записи транзакцию на Serializable помечать READ ONLY явно.

Не делать: не ставить Serializable по умолчанию везде; не считать ошибку сериализации поводом доверять данным, прочитанным в откатившейся транзакции.

Источник: PostgreSQL docs — Transaction Isolation.
