# Карты: базовая карта, четыре обязательных шаблона, стандарт обозначений, линтер, редактор

Нынешние карты не дают человеку управлять ими: правки нет, обозначения случайные, внутри групп серые квадраты, внешние связи не видны, записи карт мешают подтверждать. Меняет ADR-0035 (стратегическая карта — не шаблон), ADR-0028 (пять фиксированных стилей связей) и ADR-0006 для карт (граф рисуем сами).

## Решения

1. **Все карты — одна сущность.** Базовая карта с подключаемыми возможностями (шаблонный метод плюс композиция возможностей; фабрика создаёт карту нужного вида). Любая карта умеет то, что умеет базовая.
2. **Четыре обязательные карты** — встроенные шаблоны со своим поведением:

   | Карта | Вопрос |
   |---|---|
   | Стратегическая | куда движется проект |
   | Доменная | почему: предметная область и её законы |
   | System Design | как будет реализовано |
   | Кодовая база | что сделано сейчас |

   Остальные — шаблоны на базовой карте, необязательные. Потоки данных и пользовательские пути — такие шаблоны.
3. **Граф — основной вид**, дерево — второй.
4. **Стандарт обозначений у каждого типа** — по признанным стандартам: стратегическая — карта возможностей и C4-контекст; System Design — C4 контейнеры и компоненты, UML развёртывания и последовательностей; кодовая база — UML пакетов и компонентов. Не хватает стандарта — дописываем свой.
5. **Цветовые группы** — токены, со значениями для светлой и тёмной темы: DDD — фиолетовые, слои — от синего к бирюзовому, DevOps и инфраструктура — оранжевый, интерфейс — зелёные, внешнее — серые. Узел получает цвет по роли; в записи цвет не пишется.
6. **Связи:** синхронный вызов — сплошная со стрелкой; событие — штрих с открытой стрелкой; данные — штрих с подписью формата; «туда-обратно» — двойной наконечник или две подписанные связи. Кривые Безье.
7. **Линтер карт.** Структурная ошибка — отказ записи с узлом, полем и строкой; одинаково для интерфейса, MCP и файлов. Отступление от стандарта — предупреждение. Обязательные параметры: у узла — имя, назначение, вид; у связи — вид и подпись.
8. **Редактор — Vue Flow + elkjs** (В-3.1): меню по правой кнопке, порты, соединение, перетаскивание, мини-карта, поиск, скруглённые узлы с цветной полосой заголовка. Шаблоны взаимодействия — по образцу узловых редакторов Unreal, Unity и Blender; их ресурсы и фирменный стиль не копируются. Граф записей процесса (ADR-0006) остаётся своим кодом; Mermaid — для выгрузки и диаграмм последовательностей; 3D — вторым режимом.
9. **Провал в узел:** щелчок — выбор и инспектор; двойной щелчок или «Открыть группу» — провал; внешние узлы по краю полупрозрачные, данные подписаны на связях; хлебные крошки.
10. **Записи карт:** наверху только ждущие, с «Подтвердить» и разницей сбоку; подтверждённые, вне суммы и история курса — в свёрнутом архиве.
11. **Правка через MCP** — тем же линтером.

## Отвергнуто

- Дорисовывать стили в код компонентов: каждый новый шаблон снова правил бы интерфейс.
- Свой редактор узлов с нуля (ADR-0006): месяцы работы ради того, что есть готовым под MIT.
