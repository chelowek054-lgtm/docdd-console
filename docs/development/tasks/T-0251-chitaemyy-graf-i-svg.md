# Читаемый общий граф, контуры групп и экспорт SVG

Переиспользовать общий холст `StandardMapGraph.client.vue`, проекцию уровней `map-scope.ts`, адаптеры прежних карт и штатный линтер. Разделить исходные связи и линии отрисовки. SVG строить из той же проекции и позиций, которые использует холст. Переходить на общий переключатель глубины по одному адаптеру, сохраняя старые ссылки. У справочника есть пути модулей, отдельной записи для `reuses` нет.

## Ожидаемый результат

Глубина, рамки, односторонние и двусторонние стрелки и SVG работают в общем графе. Доменная карта имеет содержательные группы. Линтер выявляет вновь созданные одиночные узлы, старые проекты открываются с возможностью постепенной правки. Пройдена V-0177.
