# Журнал со временем: запись часов и минут, чтение старых строк

Строка журнала пишется как 2026-10-25 14:03 · действие · подпись по project.timezone (нет пояса — местное время сервера); разбор понимает строки со временем и без (без — начало дня). Тело документа не трогается. Готово, когда новые переходы пишутся со временем, а все старые журналы разбираются без нарушений.
