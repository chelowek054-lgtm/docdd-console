# Перенести раскрытую группу на общем холсте

Переиспользовать геометрию контуров, управление масштабом Vue Flow и локальное сохранение позиций из `app/components/StandardMapGraph.client.vue`. Сохранять позиции потомков одной записью по завершении жеста.

Расширить `app/utils/map-presentation.ts`. Для каждой группы сравнить варианты на базе текущей раскладки и уплотнения пустых полос. Отбрасывать варианты с пересечением прямоугольников или недостаточным зазором. Из оставшихся выбирать меньшую площадь при сохранении порядка связанных узлов и без увеличения числа пересечений. Сравнение выполнять при автоматической раскладке. Использовать один признак связи с контуром для оформления на холсте и в SVG.

Для автоматической раскладки верхнего уровня ориентироваться на рабочую область 16:9. Сравнить исходную схему, схему с сокращёнными пустыми промежутками и несколько рядов из целых групп. Выбрать пропорции, близкие к 16:9, с учётом общей площади. В обычном режиме дать холсту ширину секции с ограничением по высоте окна, в полноэкранном использовать доступное пространство.

## Ожидаемый результат

Кнопка в правом верхнем углу раскрытого контура запускает тот же алгоритм для выбранной группы. Соседние элементы сохраняют позиции. Результат записывается в локальную раскладку представления.

Раскрытая группа перемещается целиком за заголовок или свободное место. После перезагрузки раскладка восстанавливается, щелчки и переходы работают как прежде.

При автоматической раскладке группы занимают меньше места там, где это позволяет граф. Связи контуров заметно отличаются от связей между карточками.
