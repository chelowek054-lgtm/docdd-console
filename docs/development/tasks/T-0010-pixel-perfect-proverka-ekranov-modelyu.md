# Pixel-Perfect-проверка экранов моделью против эталона

Шаблон запроса `docs/prompts/design-pixel-perfect.md`: снимок экрана, сложенные токены проекта и эталонный макет экрана, если он лежит; модель называет каждое расхождение — где, что ожидалось по токенам или макету, что на снимке.
