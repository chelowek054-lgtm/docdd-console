# Снимки экранов проекта по ширинам и темам

Список экранов — из подтверждённой карты пользовательских путей (`screens`, `server/lib/maps.ts`), адрес и способ запуска — как решит ADR из T-0001. Без снимка проверку не запускать: экран называет, каких снимков нет.
