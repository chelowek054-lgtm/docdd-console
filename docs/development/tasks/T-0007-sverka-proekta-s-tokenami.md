# Сверка проекта с токенами: файл темы и компоненты реестра

Проект объявляет стеки и пути файлов темы в `project.yaml` (как решит ADR из T-0001). Приложение сравнивает файл проекта с выгрузкой: расхождение — `design_theme_drift` с диффом во вкладке «Стеки»; компонент реестра, которого нет в коде, — `design_component_missing` (ищется по карте кода и описи файлов: `server/lib/inventory.ts`, `server/lib/maps.ts`). Запись файла темы в проект — так, как решит ADR.
