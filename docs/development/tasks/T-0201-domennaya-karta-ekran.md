# Доменная карта на экране «Стратегия»

Блок на экране «Стратегия» сразу под функциональной картой, шаг «Доменная карта» в чек-листе подключения вторым: контексты с видом и возможностями, связи между ними, раскрытие контекста до модулей, слоёв и файлов кодовой карты. Данные — через API состояния карт, компонент в файлы не ходит.

## Ожидаемый результат

На временном проекте контекст раскрывается до файла; пустая карта показывает подсказку и предупреждение.
