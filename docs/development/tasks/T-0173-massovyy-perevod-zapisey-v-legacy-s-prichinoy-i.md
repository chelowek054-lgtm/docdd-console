# Массовый перевод записей в legacy с причиной и ссылкой на карту курса

На экране записей — выбор пачкой по фильтру (тип, статус, дата, «всё до карты M-XXXX») → кнопка «Перевести в legacy» → одна причина на всю пачку, без правки тела. Каждой записи — строка журнала `- дата · в legacy: <причина> · <роль>`. Причина может нести `legacy_by: M-XXXX`; если карта названа — в её историю курса (server/lib/course.ts) пишется счётчик «отправлено в legacy: N». Списки по умолчанию скрывают legacy-записи за переключателем «показать legacy».
