# Оптимистическая блокировка на всех пишущих маршрутах

Версия записи при загрузке, отказ 409 на любой правке поверх чужой: статусы, поля, порядок, пачки. Готово, когда две вкладки, меняющие одну запись, не теряют ни одной правки молча.
