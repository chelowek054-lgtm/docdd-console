# Функциональная карта: DDD и чистая архитектура как основа проектов

Черновик: составлен моделью, не подтверждён. Вектор не меняется. Добавляется группа «Архитектура DDD + Clean»: консоль ведёт любой проект к DDD и чистой архитектуре. Модули разделены по ограниченным контекстам и слоям вплоть до файлов.
