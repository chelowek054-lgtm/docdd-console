# Курс — приложение на общем сервере для команды

Черновик: смена курса, не подтверждена. До сих пор приложение жило только на
машине одного человека (вектор: «без удалённого доступа»). Теперь его ставят на
сервер вместе с проектом, чтобы полную картину работы видели и специалисты не из
IT. Вектор заменяется целиком (повторное объявление заменяет прежнее), в
возможности добавляются развёртывание и, на потом, роли.

Решение о том, как приложение смотрит в сеть, — в
[ADR-0018](../../adr/0018-shared-server.md); порядок установки — в
[docs/14-deploy.md](../../14-deploy.md).
