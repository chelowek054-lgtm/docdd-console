# Функциональная карта: «Статус «прежний курс» (legacy) для записей»

Смена курса проекта оставляет десятки подтверждённых requirement и task, описывающих прежний вектор. Новая возможность — внутри уже существующей «Переходы по статусам, в том числе пачкой» (records.status): отдельный статус, под которым запись жива как история, но не в текущей картине.
