# Единый граф и вложенные группы стандартных карт

Одинаковый обзор групп, переходы между уровнями, счётчики и внешние связи на стратегической, доменной, System Design и кодовой картах. Шаблон стандартной карты предоставляет тот же граф другим видам, которые поддерживают вложенность. Цвета, формы и типы связей определяет стандарт каждого вида.

В доменной карте группа объединяет понятия и процессы одной области. В System Design группа объединяет компоненты одной ответственности. У обоих видов используются стабильные идентификаторы и необязательный `parent`.
