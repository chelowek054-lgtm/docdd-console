# Единый дизайн между проектами

Дизайн ведётся глобально, в самой консоли, и спускается в проекты на Nuxt + Nuxt UI, React Native + Expo, Kotlin/Compose и Swift/SwiftUI: одни токены во встроенном источнике `practices/`, выгрузка в файл темы каждого стека и проверка экранов проекта моделью — Responsive (ширины, скролл, зона нажатия) и Pixel-Perfect (снимок против токенов и эталонного макета). Готово, когда эталон PRAXIS лежит записью `docdd-design` в консоли, глобальный экран «Дизайн» показывает его и подключившие проекты, контраст ниже 4.5:1 попадает в нарушения, для каждого стека есть выгрузка и сверка, а экраны проекта проверены моделью с находками по экрану, ширине и теме.
