# Фаза 25 — безопасность общего сервера

Сервер, на который пускают команду, не даёт через консоль больше поручённого. Без ролей опасные действия выключены режимом `shared`, проекты подключаются только из разрешённых каталогов, модель не выходит за проект. Готово, когда находки 1–3 аудита закрыты, а скрипт развёртывания ставит сервер в этот режим.
