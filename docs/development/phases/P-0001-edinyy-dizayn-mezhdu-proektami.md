# Единый дизайн между проектами

Оформление проектов на Nuxt + Nuxt UI, React Native + Expo, Kotlin/Compose и Swift/SwiftUI держится на одних токенах из общего источника практик, а консоль показывает их, проверяет и сверяет с файлами темы каждого проекта. Готово, когда эталон PRAXIS лежит записью `docdd-design` в общем источнике, `learning` и `InteractMedNew` его подключили, экран «Дизайн» показывает палитру обеих тем и шкалы, контраст ниже 4.5:1 попадает в нарушения, а для каждого стека есть выгрузка и сверка файла темы.
