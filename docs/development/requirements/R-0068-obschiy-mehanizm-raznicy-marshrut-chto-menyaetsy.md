# Общий механизм разницы: маршрут «что меняется» и компонент над записью

Над любой записью в статусе «на подтверждении» есть компонент «разница записи», данные даёт общий маршрут «что меняется» (было → станет) по типу записи: карта — по сложенной картине, остальное — по тексту и полям. «Было» берётся из git и подтверждённых записей, своей базы снимков нет. Подтвердить без просмотра разницы можно, но в журнал пишется «подтверждено после просмотра разницы» только когда разница открывалась, а список «на подтверждении» показывает значок «разница не открывалась». Готово, когда маршрут отдаёт разницу для каждого типа записи, а журнал и список отражают просмотр.
