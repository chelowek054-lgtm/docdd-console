# Кодовая база: слепок с описью, назначением и внешними связями

Зачем: п. 4.5, 4.14 замечаний; решение A-0010, A-0009.

Что делаем: опись файлов — инструмент шаблона кодовой базы (вкладка открывается описью); у узла назначение одной строкой и вид по стандарту (не серый квадрат); группы показывают внешние связи; пороги деления — предупреждения; несостыковки с картой подсвечиваются; работает с любым профилем.

Готово, когда: в группе кодовой базы нет узлов без назначения, видны входящие и исходящие связи.
