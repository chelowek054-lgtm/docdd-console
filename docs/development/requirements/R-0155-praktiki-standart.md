# Практики: обязательный шаг и новый экран

Зачем: п. 6.2 замечаний; решение A-0016.

Что делаем: шаг «Практики» в допросе создания и подключения — предложение по профилю и языкам, снятие лишнего; экран «Практики»: «Включено в проекте» (что проверяет, сколько нарушений, ссылка на нарушения) и «Каталог» отдельно; предупреждение `practices_none` у проекта с кодом без практик.

Готово, когда: новый проект не проходит подключение без шага практик; экран показывает включённое с числами.
