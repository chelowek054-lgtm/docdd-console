# Grafana: метрики процесса, алерты во входящее, ссылки на панели

Консоль отдаёт метрики процесса для Prometheus (задачи по статусам, нарушения, доля пройденных проверок, расход на модели); алерт Grafana по webhook становится заметкой во входящем; у возможности — ссылки на панели. Своей базы метрик нет. Готово, когда панель Grafana строится по метрикам консоли, а алерт появляется во входящем.
