# Карта System Design

Зачем: п. 4.11, 4.12, 4.14 замечаний; решение A-0011.

Что делаем: шаблон `sysdesign`: узлы-модули с `realized_by`, `detail: template | detailed` и обязательными разделами подробного узла; раздел «Стандарты» (линтеры, покрытие) с проверкой конфигов и покрытия; требования `quality` с проверкой-метрикой; решения архитектора по областям — ссылками; стандарт C4 и UML развёртывания.

Готово, когда: подробный узел без нагрузки не проходит линтер; стандарты дают предупреждения о нехватке конфигов.
