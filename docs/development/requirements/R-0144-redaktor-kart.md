# Редактор карт мышью на Vue Flow и elkjs

Зачем: п. 4.8, 4.9 замечаний; решение A-0010.

Что делаем: компонент карты на Vue Flow; раскладка elkjs; узлы скруглённые с цветной полосой заголовка; порты; меню по правой кнопке «Добавить узел» с поиском по видам стандарта; соединение мышью; перетаскивание; мини-карта; масштаб. Правки — черновиком записи карты через линтер. ADR-0006 получает пометку «для карт изменено A-0010».

Готово, когда: на собранной консоли карту можно собрать мышью и подтвердить.
