# Обсуждение у записи

У записи есть обсуждение: замечания ревьюера и ответы хранятся файлом рядом с записью в репозитории, не меняя текст документа; закрытое замечание помечается. Готово, когда на карточке записи можно оставить и закрыть замечание.
