# Снимки историй — эталон Pixel-Perfect и визуальных регрессий

Снимки историй каталога, собранные CI проекта по стекам, становятся эталоном проверки экранов: Pixel-Perfect сравнивает перенесённый компонент со снимком истории Storybook; консоль снимков не делает. Готово, когда запрос Pixel-Perfect принимает пару «эталон истории — снимок стека».
