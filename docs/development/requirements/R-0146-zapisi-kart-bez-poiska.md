# Записи карт: ждущие наверху, архив свёрнут

Зачем: п. 4.13 замечаний; решение A-0010.

Что делаем: в «Записях карт» наверху только ждущие подтверждения, у каждой — «Подтвердить», которая сбоку показывает разницу (`MapDiff`) и подтверждает. Подтверждённые, вне суммы и история курса — один свёрнутый «Архив карт» с числом. Заменяет черновик R-0132.

Готово, когда: новая карта подтверждается с экрана «Карты» без поиска.
