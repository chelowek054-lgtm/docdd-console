# Регрессионный прогон: лид нарезает, тестеры отмечают

Зачем: п. 5.4 замечаний; решение A-0013.

Что делаем: запись прогона — список проверок с исполнителями; лид назначает; тестер видит «Мои» и отмечает «прошло / не прошло / заблокировано» с текстом; итог прогона — сводка, непрошедшее — дефекты.

Готово, когда: прогон на трёх тестеров проходит от нарезки до сводки.
