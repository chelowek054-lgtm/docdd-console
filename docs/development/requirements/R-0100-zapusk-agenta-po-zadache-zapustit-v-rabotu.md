# Запуск агента по задаче: «Запустить в работу»

Кнопка «Запустить в работу» на задаче, исполнитель которой — аккаунт агента: консоль выдаёт токен на запуск (ADR-0033), берёт определение агента (docs/agents/<id>.md по типу аккаунта), собирает контекст — задачу и её связи, глобальные правила проекта (CLAUDE.md, практики, вектор, карты), данные агента — и запускает его через провайдера в ветке задачи (ADR-0009) с его системным промптом и моделью. Агент двигает статусы через API своим токеном; ограничения ADR-0033 действуют. Лимит токенов на задачу (R-0093) применяется. Готово, когда задача с исполнителем-агентом запускается кнопкой, в журнале видны переходы с подписью агента, а попытка агента подтвердить документ отклоняется.
