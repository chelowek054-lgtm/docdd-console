# Стандарт обозначений у каждого типа карты

Зачем: п. 4.3, 4.6 замечаний; решение A-0010.

Что делаем: файл стандарта у каждого встроенного шаблона — виды узлов (форма, цветовой токен, значок), виды связей (линия, наконечники, подпись, «туда-обратно»), легенда. Цветовые группы и значения для двух тем — в токенах. Шаблон проекта может переопределить стандарт по частям (`extends`). Справка: какие стандарты взяты (C4, UML, карта возможностей) и что добавлено своё.

Готово, когда: у четырёх обязательных шаблонов есть стандарт; легенда строится из него; контраст токенов проходит AA в обеих темах.
