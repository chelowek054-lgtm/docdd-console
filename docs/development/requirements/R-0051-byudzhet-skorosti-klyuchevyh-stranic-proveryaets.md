# Бюджет скорости ключевых страниц проверяется прогоном

Скрипт npm run perf открывает ключевые страницы проекта (обзор, работа, карты по вкладкам, карточка записи, проверки, дизайн) на запущенной консоли и пишет отчёт в tests/reports: время первого байта, размер HTML и payload по странице; бюджеты лежат в одном файле рядом со скриптом и ссылаются на проверки-метрики требований скорости (passed/failed по каждой V-…). Не делаем: замер в CI и сравнение с прошлыми прогонами. Готово, когда прогон пишет отчёт, который консоль читает как результат проверок-метрик.
