# Сквозные связи через уровни скрыты и подсвечиваются при выборе узла

Связь функциональной карты между узлами, где один не предок другого и глубины разные, — сквозная. По умолчанию на схеме она скрыта; при выборе узла его сквозные связи показываются пунктиром другого цвета с подписью «минует уровни». Готово, когда функция находит сквозные связи (тест) и карта показывает их только для выбранного узла.
