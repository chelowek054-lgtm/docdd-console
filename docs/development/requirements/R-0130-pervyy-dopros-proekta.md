# Первый допрос проекта при создании и подключении

Зачем: курс задаётся один раз в начале, и без него проект не стартует вслепую (A-0006, п. 2, 5, 6).

Что делаем:
- Допрос проекта — обязательный шаг чек-листа подключения у обоих сценариев, первым после `project.yaml`. Шаг выполнен, когда в `project.yaml` есть `grill: { level, session }` и сессия закрыта.
- Новый проект: уровень выбирает человек по подсказке A-0006, п. 2. Готовый: консоль показывает подсказку по фактам (модули, контексты, записи, контракты), модель предлагает уровень, выбирает человек.
- Подключение: обязательная тема, закрытая фактами, отмечается закрытой со ссылкой на факт. Человека спрашивают только о решениях и противоречиях.
- Предупреждение `project_not_grilled`, пока шага нет. При включённых `gates.grill` ни одна задача с `change: feature` не уходит в `ready`. Мастер нового проекта заводит `project.yaml` с `gates.grill: true`.
- Повторный допрос при смене курса остаётся по желанию. Он пишется той же сессией `kind: project`, а `project.yaml` указывает на последнюю.

Чего не делаем: не включаем ворота у подключённого проекта сами.

Готово, когда: чек-лист показывает шаг и отмечает его; подсказка уровня у подключения строится по фактам; `project_not_grilled` и ворота работают; новый проект заводится с воротами.
