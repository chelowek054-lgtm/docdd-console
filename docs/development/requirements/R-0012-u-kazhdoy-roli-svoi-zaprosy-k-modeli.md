# У каждой роли свои запросы к модели

Менеджер, аналитик, доменный специалист и наблюдатель спрашивают модель своими шаблонами из `docs/prompts/roles` и получают ответ по своему контексту. Ответ — черновик, применяет человек. Готово, когда у каждой роли есть хотя бы один рабочий запрос из её рабочего места.
