# У задачи есть исполнитель, а наблюдатель только смотрит

Задача называет исполнителя (`assignee`), и у каждого есть список «Мои задачи». Роль `viewer` видит ход работы, но ничего не меняет. Готово, когда фильтр по исполнителю работает на экранах работы, а наблюдатель не может изменить ни одной записи.
