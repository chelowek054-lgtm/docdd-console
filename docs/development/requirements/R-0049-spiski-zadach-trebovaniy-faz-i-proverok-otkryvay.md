# Списки задач, требований, фаз и проверок открываются без длинных задач

Строки списков рисуются лёгкой разметкой: метки статуса, фазы, тега и факта проверки — span с классом из общей таблицы цветов вместо компонента на каждую метку; производные по строке (факт проверки, ревьюер, ожидающие опоры) считаются один раз картой по id из обратных связей индекса, а не перебором всех записей для каждой строки; первая порция списка — не больше, чем помещается на два экрана. Вид меток для человека не меняется. Готово, когда на docdd-console длинная задача при переходе на /work, /checks, /phases, /requirements и /documents короче 100 мс.
