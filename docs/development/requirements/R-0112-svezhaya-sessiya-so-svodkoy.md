# Разросшаяся сессия заменяется новой с короткой сводкой

Зачем: продолжение сессии экономит проход по коду, но большая история оплачивается целиком на каждом шаге.

Что делаем: при повторном заходе консоль сравнивает размер прошлой сессии с порогом из `llm.json`. Выше порога — новая сессия с пакетом задачи, диффом ветки и замечанием человека; в ленте строка о причине. Порог задаётся по данным R-0109.

Чего не делаем: не меняем поведение ниже порога; сводку собирает код, а не модель.

Готово, когда: выше порога заход начинается заново со сводкой, ниже — продолжает сессию; на сравнении с базовой линией расход не вырос, а проверки не стали падать чаще.
