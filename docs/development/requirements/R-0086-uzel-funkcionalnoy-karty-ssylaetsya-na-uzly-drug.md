# Узел функциональной карты ссылается на узлы других карт

У возможности функциональной карты — ссылки на узлы других карт: модули кодовой базы, пути, узлы своих карт (ADR-0028), в виде «вид:узел». Обратная сторона видна у узла другой карты («реализует возможность …»). Ссылка на несуществующий узел — предупреждение валидатора. Готово, когда ссылки задаются в карточке возможности, видны с обеих сторон и битая ссылка находится валидатором.
