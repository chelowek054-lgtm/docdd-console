# Перенос компонента на стек моделью по контракту

Запрос модели «перенести компонент на стек» собирает контракт, истории, токены стека и соседние перенесённые компоненты; модель работает в ветке задачи, сливает человек. Готово, когда из карточки компонента можно собрать такой запрос.
