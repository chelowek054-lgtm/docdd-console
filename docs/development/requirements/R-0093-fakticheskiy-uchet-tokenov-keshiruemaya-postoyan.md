# Фактический учёт токенов, кэшируемая постоянная часть запроса и лимит на задачу

Расход считается по токенам из ответа провайдера (input/output/cache), а оценка по символам — только когда провайдер их не отдал, и помечена «≈». Пакет контекста ставит постоянную часть (вектор, сжатая карта, практики, правила) первой и одинаковой, чтобы провайдер кэшировал её. У маршрутов по умолчанию: разбор входящего и сверка — чат-модель, код — агент. У задачи — лимит токенов; превышение останавливает запрос с понятной причиной. Готово, когда учёт по факту и порядок пакета покрыты тестами, а лимит останавливает запрос.
