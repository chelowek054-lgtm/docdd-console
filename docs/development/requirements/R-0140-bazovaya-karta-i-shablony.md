# Базовая карта и четыре обязательных шаблона

Зачем: п. 4.1, 4.14, 4.15, 10.1 замечаний; решение A-0010.

Что делаем:
- Модуль `server/lib/map-core/`: базовая карта (узлы, связи, вложенность, свидетельства, здоровье) и реестр возможностей; шаблон — набор возможностей и своё поведение.
- Встроенные обязательные шаблоны: `strategic` (бывшая `functional`, имя в файлах прежнее), `domain`, `sysdesign`, `codebase` (бывшая `codemap`). Отсутствие любой — предупреждение `map_required_missing` (у проекта без кода — кроме кодовой базы).
- `dataflow` и `userflow` — обычные шаблоны.
- Экран «Карты»: четыре обязательные вкладки первыми; граф по умолчанию, дерево — переключателем.
- ADR-0035 и ADR-0028 получают пометку «изменено A-0010».

Готово, когда: старые записи читаются без правки файлов; четыре вкладки; предупреждение о пропуске.
