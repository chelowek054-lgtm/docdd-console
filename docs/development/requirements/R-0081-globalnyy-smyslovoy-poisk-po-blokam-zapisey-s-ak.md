# Глобальный смысловой поиск по блокам записей с актуальным индексом

Лупа в шапке и Ctrl+K открывают окно поиска поверх текущего экрана, без перехода на страницу; пока запрос не введён, к серверу не обращаемся. Сервер делит записи на блоки по разделам, хранит эмбеддинги блоков в .docdd/embeddings.jsonl (кэш, нормализованные векторы), считает сходство скалярным произведением потоком пачками и возвращает лучшие N со ссылкой на запись и раздел. Индекс актуален сам: сверка по отпечатку файлов, досчёт только блоков с новым хешом, удалённые выпадают, смена модели — пересборка, прогрев после записи консолью, команда npm run embeddings для CI. Эмбеддинги — провайдер из настроек моделей или локальный хеш-эмбеддинг без сети. Готово, когда поиск находит запись по смыслу запроса с любого экрана и индекс не требует ручного обслуживания (ADR-0031).
