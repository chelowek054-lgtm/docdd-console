# Сверка пачки: требования, задачи и проверки функции — одним отчётом

Заметка входящего несёт метку роли автора и метку функции. Сверка пачки по функции (возможности) — чистая функция: требования без проверок, задачи без требований, проверки без шагов или команды, требования без задач. Отчёт показывается на возможности; пока в нём есть ошибки, задачи функции не переходят в ready (правило перехода). Готово, когда отчёт считается тестом на каждый вид пробела и перевод в ready с непустым отчётом отклоняется с перечнем.
