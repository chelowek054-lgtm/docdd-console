# Шаблон проекта software-core: контуры, карты по ролям, роли

Шаблон проекта — данные, а не движок: контуры стратегического уровня, заготовки своих карт по ролям, роли команды. Первый — software-core: контуры «Продукт и требования», «Архитектура и код», «Интерфейс и дизайн», «Инфраструктура и выкладка», «Качество и безопасность», «Выпуск и поддержка». gamedev — следующим, llm-product — по появлению такого проекта; отдельного ai-agentic-dev нет: агенты ролей — в ядре. Готово, когда заведение нового проекта с шаблоном software-core даёт функциональную карту с контурами, роли в манифесте и заготовки карт.
