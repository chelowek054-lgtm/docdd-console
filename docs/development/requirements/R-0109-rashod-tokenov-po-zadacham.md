# Расход токенов виден по задачам, есть базовая линия

Зачем: без замера нельзя понять, какой модуль экономии нужен и сработал ли он.

Что делаем: отчёт из `.data/llm-usage.jsonl`: вход, выход, чтение и запись кэша, число заходов по задаче и виду запроса. Отчёт на экране моделей и в `cli/token-report.ts`. Базовая линия сохраняется файлом в `tests/reports`, и новые замеры сравниваются с ней.

Чего не делаем: новое хранилище; оценка без пометки: где провайдер не отдал токены, значение отмечено как оценка.

Готово, когда: по любой задаче видно, сколько она стоила и на что ушло; базовая линия записана до включения остальных модулей экономии.
