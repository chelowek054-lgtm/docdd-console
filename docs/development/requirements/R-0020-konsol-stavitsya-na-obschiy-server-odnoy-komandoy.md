# Консоль ставится на общий сервер одной командой

Скрипт `deploy/deploy.sh` ставит нужную версию Node, собирает приложение, заводит службу и nginx с авторизацией; повторный запуск обновляет (docs/14-deploy.md). Готово, когда скрипт прошёл на чистом сервере Ubuntu и на сервере с Docker на порту 80.
