# Отметить по фактам: отставшие отметки возможностей чинятся черновиком карты

Предупреждение `capability_behind` (все задачи возможности закрыты, а она «Не реализовано» или не оценена) чинится одним действием. На экране «Стратегия» строка «Отметки отстали от фактов: N возможностей» с кнопкой «Отметить по фактам»: список отставших с предложенной отметкой — «Реализовано», если проверки есть и все пройдены, иначе «Частично» — и причиной. Человек снимает лишнее и меняет отметки; «Завести черновик» заводит одну запись `map` в статусе `draft` пакетной сменой отметок (меняются только `status` и `note`). Отметка меняется только подтверждением черновика (docs/07-maps.md, «Отметить по фактам»; docs/03-server-api.md, `GET /map/behind`). Готово, когда при отставших строка видна, черновик заводится с выбранными строками, после его подтверждения предупреждения по этим возможностям пропадают, а без отставших строки нет.
