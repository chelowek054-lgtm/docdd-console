# Страницы проекта не встраивают индекс целиком

Индекс проекта делится на лёгкую часть (id, тип, статус, заголовок, фаза, теги, связи, результаты проверок) и тяжёлую (нарушения, extra, обратные связи) — тяжёлая приходит отдельным запросом там, где нужна; на страницах, где индекс второстепенный, он грузится после показа. Данные и поведение экранов не меняются. Готово, когда HTML карточки записи меньше 80 КБ, а /work — меньше 200 КБ на docdd-console.
