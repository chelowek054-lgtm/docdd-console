# ML и R&D: профиль конвейера и карта развилок

Зачем: п. 10.3 замечаний; решение A-0011.

Что делаем: профиль ML у System Design и кодовой базы — узел-этап с входами и выходами, форматами, состоянием, метриками; шаблон «Развилки»: гипотеза → эксперимент (прогоны, `run_id`) → цифры → решение, отброшенные ветки подписаны, строится по записям `decision` и их `supersedes`; метрики этапов — из отчётов прогонов как проверок-метрик. Пример — конвейер GenAi.

Готово, когда: «конвейер сегодня / цель» проекта GenAi воспроизводится в консоли без артефакта.
