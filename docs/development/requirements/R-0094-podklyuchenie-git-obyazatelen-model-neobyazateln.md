# Подключение: git обязателен, модель необязательна, выбор шаблона, обучение

При подключении проверяется git-репозиторий; нет — консоль предлагает git init с ветки main только с согласия человека. Модель необязательна: без неё — каркас из шаблона проекта. При новом проекте выбирается шаблон. После подключения — короткое обучение (стратегия и карты, почему задача не уходит без документа, работа с моделью через ветку и дифф) с кнопкой «Пропустить», пройденное помнится. Проверки V-0075…V-0080 дописываются, когда берутся T-0139…T-0144. Готово, когда проверка git и согласие на init работают, обучение показывается один раз и пропускается.
