# Обзор проекта показывает реализованность, фазы до прода, проверки, метрики и риски

Обзор проекта показывает: процент реализованных требований (все задачи закрыты и все проверки пройдены), процент закрытых задач с полосой по статусам, проверки отдельно автотесты и ручные приёмки с упавшими и не запускавшимися, готовность возможностей функциональной карты, фазы конвейером со стадией (в проде, на стенде, на проверке, в разработке, не начата, закрыта) по релизам и окружениям, просроченные вехи, последние релизы, последний прогон автотестов и ручные приёмки, метрики продукта из Prometheus по запросам секции observability манифеста, риски. Готово, когда расчёт — чистая функция server/lib/overview.ts с тестом, а экран показывает всё это на любом проекте (docs/04-ui.md, «Обзор»).
