# Автопоиск источников и указание папок с экрана

Приложение находит источники проекта: папки кода, клиента, документации, тестов; файлы OpenAPI, proto, JSON-схем; файл зависимостей; отчёты CI — и предлагает человеку подтвердить; подтверждённое записывается в project.yaml (sources) приложением. Экран «Импорт» при пустом sources.docs предлагает указать папки прямо там, с найденными вариантами, вместо тупика. Готово, когда на готовой кодовой базе источники находятся без ручной правки project.yaml, а импорт стартует с экрана.
