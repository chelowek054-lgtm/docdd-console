# У каждой задачи есть проверка; любая проверка принимается вручную с записью

Задача без единой проверки (ни через требования implements → verified_by, ни своей verified_by) получает предупреждение task_no_verification с состояния ready, а при включённой политике require_verification_before_done не переводится в done. Проверка — запись со своим результатом; отметку «Проверено» можно поставить у проверки любого вида (manual, review, unit, integration, metric), у автоматических видов честно помеченную (verification_kind в отчёте, «вручную (вид unit)» в журнале, на экране «принята вручную, прогона сборки не было») и с обязательной заметкой «что проверено»; позднейший прогон сборки заменяет ручную приёмку. Ручная приёмка называет роль, имя проверившего и что проверено. Готово, когда на записи проверки вида unit есть «Проверено» с приёмкой, окно «Принять вручную» принимает проверки любого вида, а task_no_verification видна в нарушениях (ADR-0029).
