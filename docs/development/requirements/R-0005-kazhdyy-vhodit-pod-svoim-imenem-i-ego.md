# Каждый входит под своим именем, и его действия подписаны им

Человек входит в консоль по своей учётной записи; строка журнала, ручной отчёт «Проверено» и коммит в ветке задачи несут его имя и роль, а не выбранную из списка подпись. Готово, когда без входа консоль не отвечает, а журнал показывает имя.
