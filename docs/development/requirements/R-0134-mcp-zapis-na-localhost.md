# Запись через MCP без входа — только на localhost

Зачем: В-1.3 замечаний; решение A-0008.

Что делаем:
- `cli/mcp.ts` разрешает инструменты записи без входа, если `/api/auth/me` отвечает `required: false` и адрес консоли — `localhost`, `127.0.0.1` или `[::1]`.
- Со входом — как прежде: только токен агента.
- Ответ отказа называет причину: «запись без входа — только на localhost».

Готово, когда: решение о записи — чистая функция, проверенная на четырёх случаях.
