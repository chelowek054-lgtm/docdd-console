# Страница карт получает и рисует только открытый вид карты

Ответ карты на странице карт приходит по виду: при открытии в HTML встраивается только открытая вкладка (функциональная, кодовая база, потоки, пути, пользовательские), остальные виды догружаются при переключении и держатся в памяти страницы; числа на ярлыках вкладок — из лёгкой сводки. GET /map без параметра по-прежнему отдаёт всё (обратная совместимость для запросов и CLI). Готово, когда payload /maps на функциональной вкладке меньше 120 КБ, а переключение вкладок показывает данные без перезагрузки страницы.
