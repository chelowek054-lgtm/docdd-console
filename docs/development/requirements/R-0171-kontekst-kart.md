# Обязательный контекст карт для LLM

Модель получает цель карты, схему полей, применённую легенду, правила связей, источники и текущее состояние до составления правки. Большие карты читаются по группе или странице. Кодовая карта дополнительно предоставляет опись партии, правила описания файлов и формат свидетельств.

Инструкции доступны в интерфейсе базовой карты и через MCP. Подсказки генерации получают тот же контекст до вызова модели. Сервер выдаёт подтверждение получения контекста, привязанное к проекту, карте и ревизии. Запись от модели через MCP или локального помощника требует это подтверждение. При несовпадении сервер указывает, как перечитать контекст. Черновик проверяется линтером и проходит приёмку человеком.

Для внешних CLI действуют инструкции репозитория и линтер. Сервер контролирует запись через свои инструменты.
