# Функциональная карта открывается быстро: действия строки рисуются по требованию

Дерево функциональной карты не рисует у каждой возможности скрытые кнопки действий и компоненты меню: панель действий одна, появляется у строки под курсором или в фокусе (с клавиатуры тоже), шеврон и состояние — лёгкие кнопки, меню состояния создаётся по нажатию. Поведение и вид для человека не меняются: те же действия, те же подсказки, то же меню отметок. Не делаем: виртуализацию дерева и смену вида карты. Готово, когда на проекте docdd-console (119 возможностей) /maps отдаёт первый байт быстрее 0,6 с в режиме разработки, HTML меньше 350 КБ, а длинная задача при переходе на карту короче 200 мс.
