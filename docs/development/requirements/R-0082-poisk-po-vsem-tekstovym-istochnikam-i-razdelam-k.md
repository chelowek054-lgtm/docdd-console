# Поиск по всем текстовым источникам и разделам консоли

Глобальный поиск находит, кроме записей и неразобранных заметок, разобранные заметки, глоссарий, обсуждения у записей и документацию проекта (README, docs/** вне docs/development и входящего, папки sources.docs), с ссылкой на просмотр файла; и пункты меню консоли (видимые роли и общие экраны) по подписи, группе и синонимам — отдельной секцией другим цветом, для того, кто потерялся. Код и практики других проектов не входят. Готово, когда запрос «доска» находит раздел «Работа › Менеджер», а запрос по тексту ADR находит сам документ (ADR-0031).
