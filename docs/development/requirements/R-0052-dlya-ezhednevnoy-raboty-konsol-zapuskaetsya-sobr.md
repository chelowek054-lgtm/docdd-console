# Для ежедневной работы консоль запускается собранной

Есть команда запуска консоли на собранной версии (сборка и запуск .output) для ежедневной работы, описанная в README и docs/08-usage.md; режим разработки остаётся для правки самой консоли. Готово, когда полная загрузка страницы в собранной версии не тянет сотни отдельных модулей и человек знает, какой командой запускать.
