# Чек-лист «Готовность проекта» и запуск подключения

На Обзоре — карточка «Готовность проекта»: шаги подключения со статусом (не начато / готово / ждёт подтверждения), вычисленным по состоянию проекта (есть ли вектор, возможности, требования с проверками, глоссарий, источники, карты, контракты, справки, проверки из тестов). Вкладка «Подключение» в группе «Наполнение» показывает те же шаги с кнопкой «Запустить подключение»: автоматические шаги выполняются сразу, шаги с моделью ставятся в очередь; каждый шаг перезапускаемый, ничего не перетирает, даёт черновики. При заведении на главной — выбор сценария: новый проект или готовая кодовая база. Готово, когда чек-лист считается чистой функцией и на пустом проекте показывает все шаги «не начато», а на docdd-console — реальное состояние.
