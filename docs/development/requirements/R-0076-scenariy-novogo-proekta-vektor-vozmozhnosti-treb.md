# Сценарий нового проекта: вектор, возможности, требования, глоссарий

Для нового проекта мастер ведёт по шагам: вектор (четыре поля), первые возможности функциональной карты, требования под них с проверками, глоссарий (glossary.md с примером), подключение практик, фазы и первые задачи; бриф можно положить во входящее и разобрать моделью. Все записи — черновики. Готово, когда новый проект проходит мастер до первой задачи «готова к работе» без ручной правки файлов.
