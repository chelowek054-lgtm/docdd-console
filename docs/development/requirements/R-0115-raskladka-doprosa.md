# Итог допроса раскладывается в черновики документов

Зачем: ответы полезны, только когда становятся картой, ТЗ и задачами.

Что делаем: режим `grill` разбора входящего над заметкой сессии. Предложение: карта с вектором и возможностями; требования с «Готово, когда»; проверки; задачи с разделом «Ожидаемый результат», разбитые на фазу; проектные документы `design` по экранам и тону интерфейса; `decision` там, где выбор уже сделан; `design` «Риски и открытые вопросы» со всеми подводными камнями и незакрытыми темами. Показывается тем же списком с правкой и снятием пунктов. У каждой записи — `derived_from` на заметку сессии.

Чего не делаем: ничего не подтверждаем; у подключённого проекта не переписываем существующий текст (ADR-0011): новые записи и вопросы.

Готово, когда: завершённая сессия даёт предложение, заводятся только черновики, каждая запись ведёт к заметке, открытые вопросы не теряются, а записи заведённого проекта проходят `npm run check` без ошибок.
