# Проверка задачи вопросами

Зачем: человек не должен читать весь дифф, чтобы понять, сделано ли обещанное; а модели нельзя принимать собственную работу.

Что делаем: кнопка «Проверить вопросами» у задачи `in_review`. Модель без инструментов получает ожидаемый результат, требование, проверки и дифф ветки в пределах бюджета и отдаёт 3–5 вопросов: что проверить, как проверить, какой ответ ожидаем. Человек отвечает «да», «нет» или «не проверял», можно с комментарием. Ответы пишутся в обсуждение записи, итог — в журнал. Хотя бы одно «нет» предлагает «На доработку» с текстами вопросов. Обратно из доработки вопросы задаются заново.

Чего не делаем: не закрываем задачу по ответам; не блокируем закрытие без вопросов; модель не видит того, что помечено `confidential`.

Готово, когда: у задачи на проверке появляются вопросы, связанные с её ожидаемым результатом; ответы сохраняются; «нет» уводит в доработку с текстом; закрыть может только человек, а агент не отвечает на вопросы по своей задаче.
