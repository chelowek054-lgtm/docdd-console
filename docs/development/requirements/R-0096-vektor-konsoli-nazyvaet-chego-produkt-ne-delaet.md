# Вектор консоли называет, чего продукт не делает

В векторе docdd-console поле «Чего продукт не делает» перечисляет: сферы вне IT; бюджет и учёт ресурсов; опрос внешних систем из узлов карты; собственные жизненные циклы под сферу; провайдеры бинарных свидетельств (заложено только поле «вид» свидетельства). Готово, когда вектор подтверждён с этими пунктами.
