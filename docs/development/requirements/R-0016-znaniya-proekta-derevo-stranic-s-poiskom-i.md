# Знания проекта — дерево страниц с поиском и глоссарием

Документы, решения, контракты и база знаний доступны деревом, как страницы Confluence, с поиском по тексту и глоссарием, термины которого попадают в пакет контекста. Готово, когда на живом проекте любой документ находится поиском за одно действие.
