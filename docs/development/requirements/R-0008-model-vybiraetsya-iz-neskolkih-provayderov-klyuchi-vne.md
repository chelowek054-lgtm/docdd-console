# Модель выбирается из нескольких провайдеров, ключи вне репозитория

Консоль работает с несколькими провайдерами через один интерфейс: агентами (Claude Code и другие) и чат-моделями по API (OpenAI-совместимые, Anthropic). Ключи задаются переменными окружения сервера и не попадают ни в записи, ни в браузер. Готово, когда запрос одного вида можно отправить двумя разными провайдерами с тем же результатом для экрана.
