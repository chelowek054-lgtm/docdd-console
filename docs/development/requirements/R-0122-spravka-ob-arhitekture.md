# Справка об архитектуре для нового человека

Зачем: новый человек должен сразу знать, что все проекты стремятся к DDD + Clean и что глобальное решает архитектор. Иначе предупреждения о слоях выглядят как придирки.

Что делаем:
- Документ `docs/18-architecture.md`: зачем доменную логику отделять от инфраструктуры; контекст, сущность, объект-значение, агрегат и корень, политика, единый язык и прикладной слой на одном примере (рейсы и зарплатная ведомость); сводная таблица «есть ли ID / изменяемость / главная задача / пример»; слои; как читать доменную карту; что значат предупреждения; что решает архитектор и почему модель только предлагает.
- Четвёртый шаг обучения на странице проекта: «Архитектура» — коротко то же самое со ссылкой на документ.
- README (ru и en) и `docs/08-usage.md` получают короткий раздел со ссылкой.

Чего не делаем: не пересказываем книги по DDD — только то, что видно в консоли.

Готово, когда: обучение показывает четыре шага, четвёртый ведёт на справку; документ есть и на него ссылаются README и руководство.
