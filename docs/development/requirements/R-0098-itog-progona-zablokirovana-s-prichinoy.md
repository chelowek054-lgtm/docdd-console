# Итог прогона «заблокирована» с причиной

Отчёт прогона принимает итог blocked с обязательной причиной (текст и, по возможности, номер мешающей записи). На «Сверке» — плашка «Заблокированы»; в «Прогоне» — выбор «заблокирована» с полем причины; в карточке проверки — причина в истории. Заблокированная не считается ни пройденной, ни проваленной. Готово, когда blocked пишется в отчёт, читается индексом и виден на Сверке.
