# Вид запроса определяет модель, и каждый запрос учтён

В настройках сказано, какой вид запроса какой моделью идёт. Запрос, которому нужны инструменты, не уходит чат-модели. Каждый запрос оставляет строку учёта: кто, вид, модель, размер, время, цена. Готово, когда маршрутизация и учёт видны на экране «Модели».
