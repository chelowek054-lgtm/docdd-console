# Контракты, справки и глоссарий из кода и документации

Из OpenAPI, proto и JSON-схем в коде заводятся контракты со ссылкой на файл; из файла зависимостей — справки; из терминов документации — глоссарий. Всё черновиками с указанием источника. Готово, когда на готовой кодовой базе контракты, справки и глоссарий появляются шагом подключения.
