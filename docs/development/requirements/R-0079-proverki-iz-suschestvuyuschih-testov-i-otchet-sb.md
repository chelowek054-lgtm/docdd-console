# Проверки из существующих тестов и отчёт сборки

Приложение находит тестовые файлы проекта, сопоставляет их с требованиями (пути, имена, свидетельства карты кода) и предлагает проверки вида unit/integration с командой запуска; подключает отчёт сборки раннера проекта. Готово, когда на готовой кодовой базе видно, какие требования покрыты тестами, без ручного заведения проверок.
