# Чат harness в шапке проекта

В группе «Работа» шапки проекта есть ссылка «Чат» с отдельным адресом. На странице видны сообщения, выбранный сценарий, состояние запроса и источники использованного контекста. Панель ввода остаётся доступной при прокрутке длинного диалога. Запрос можно остановить или повторить после ошибки.

В первом срезе три шаблона. Разработчик получает задачу и связанные записи о реализации и проверках. Архитектор получает требования, решения и карты. Остальные роли используют общий шаблон вопросов по проекту. Роль шапки задаёт начальный шаблон. Пользователь может переключить шаблон, права на чтение определяет сервер.

Ответ использует текущий проект и один модельный запрос на ход. Продолжение использует ограниченную историю и повторно используемый контекст задачи. Ссылки в ответе относятся к записям, реально переданным модели. Первый срез работает в режиме чтения. Сессия записи связана с T-0241.
