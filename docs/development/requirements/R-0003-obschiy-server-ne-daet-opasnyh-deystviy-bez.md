# Общий сервер не даёт опасных действий без прав

На сервере, куда заходит команда, свободный запрос к модели, работа модели с полным доступом, слияние и добавление проектов недоступны, пока у человека нет на это права. Проекты подключаются только из разрешённых каталогов. Готово, когда в режиме `shared` эти маршруты отвечают отказом с причиной, а локальный режим работает как прежде.
