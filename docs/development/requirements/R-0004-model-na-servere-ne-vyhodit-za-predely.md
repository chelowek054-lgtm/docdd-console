# Модель на сервере не выходит за пределы проекта

Запущенная на сервере модель читает и пишет только внутри корня проекта (или рабочего дерева задачи) и не видит секретов сервера и чужих проектов. Готово, когда попытка прочитать файл вне проекта через запрос к модели отклоняется, а работа над задачей идёт в рабочем дереве под ограниченными правами.
