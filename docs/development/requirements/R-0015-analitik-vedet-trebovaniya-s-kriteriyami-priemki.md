# Аналитик ведёт требования с критериями приёмки

В требовании есть критерии приёмки, и из них заводятся черновики проверок. Помощник аналитика уточняет требование, находит противоречия с другими требованиями и картой, предлагает критерии. Готово, когда из критериев требования одним действием заводятся черновики `V-`.
