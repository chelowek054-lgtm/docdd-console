# Новые проекты и люди добавляются без перестройки процесса

Портфель показывает все проекты, доступные человеку. Новый проект заводится по шаблону с вектором, ролями и практиками, а у возможностей и фаз есть владельцы. Готово, когда новый проект с командой из трёх ролей заводится за одно действие и сразу проходит проверку без ошибок.
