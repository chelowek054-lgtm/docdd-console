# «Принять вручную» видна заранее; задача без проверок принимается через ручную проверку

Зачем: п. 1 замечаний; решение .

Что делаем:
- На задаче «на проверке» кнопка «Принять вручную…» стоит рядом с «Закрыть» сразу, если хоть одна её проверка не пройдена или проверок нет.
- В окне у задачи без проверок — поле «Что проверено» и кнопка «Завести ручную проверку и принять»: заводится запись `verification` вида `manual` к требованию задачи (или к задаче, если требования нет), сразу отмечается «Проверено», задача закрывается.
- Подсказка у кнопки «Закрыть» объясняет, почему она недоступна, одним предложением.

Готово, когда: на собранной консоли задачу без автотестов и задачу без проверок можно закрыть за один заход окна.
