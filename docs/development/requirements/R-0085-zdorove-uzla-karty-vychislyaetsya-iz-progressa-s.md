# Здоровье узла карты вычисляется из прогресса, сроков, качества и нарушений

Состояние узла функциональной карты (в норме / внимание / проблема) вычисляется, а не ставится руками, и не учитывает бюджет. Сигналы: прогресс по возможностям-листьям; сроки — просрочка фаз, где стоят задачи узла; качество — проваленные и заблокированные проверки, ручные без приёмки, требования узла без проверок; нарушения — ошибки и предупреждения по связанным записям. Состояние — худшее из сигналов, сворачивается до родителя; рядом причина ссылкой. Готово, когда функция здоровья покрыта тестом на каждый сигнал и свёртку, и экран «Стратегия» показывает здоровье с причиной.
