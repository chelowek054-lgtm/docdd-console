# Восемь областей: право и поводы напоминания

Шаги: решения со всеми восемью `area`; подтверждение от разработчика и архитектора. Проекты: с доменной картой без связей и требований к качеству; с требованием `load`; с `recovery`; с `security`; с проверкой `metric`; со связью контекстов.

Ожидаемый результат: схема принимает восемь значений; разработчику `architect_only` на каждое. Без поводов напоминают только три первые области; каждый повод добавляет ровно свою область, и сообщение называет требование или связь.
