# Экран допроса на собранной консоли

Шаги: собранная консоль, временный проект, подставная или настоящая модель. «Что хотим?» с намерением среднего объёма: уровень, раунды, «Да» на рекомендацию, «Не знаю», «Общее понимание», «Верно», раскладка. Открыть заведённое требование.

Ожидаемый результат:
- уровень с причиной и темами;
- у вопросов рекомендации, «Да» записано с рекомендацией;
- раскладка только после «Верно»;
- у требования ссылка «Допрос» на заметку;
- в справке раздел с таблицами.
