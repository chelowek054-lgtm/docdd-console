# Сроки и время: разбор журнала, расчёт таймингов, перенос срока из тега

Автотесты:

- журнал: строка со временем и без читается, без времени — начало дня, часовой пояс проекта учитывается;
- тайминги: lead, cycle, время в статусах, ожидание документов, оценка против факта, просрочка — на наборе записей с
  известным ответом, в том числе с возвратом из `in_review` в `in_progress`;
- `estimate`: `30m`, `2h`, `1d` разбираются, кривое значение — нарушение схемы, а не ноль;
- перенос срока из тега: `due-2026-10-26` → `due: 2026-10-26`, тег убран, строка в журнале, незнакомые поля на месте;
- правила `task_overdue`, `phase_overdue`, `estimate_exceeded` — предупреждения, не ошибки.
