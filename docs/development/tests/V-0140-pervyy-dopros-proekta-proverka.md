# Первый допрос проекта: чек-лист, подсказка, ворота

Шаги:
- чек-лист нового и подключённого проекта без `grill` и с ним;
- подсказка уровня на проекте с тремя контекстами и контрактом и на проекте из одного модуля;
- задача-функция в `ready` при `gates.grill` без первого допроса;
- мастер нового проекта.

Ожидаемый результат:
- шаг виден и отмечается по `project.yaml`;
- подсказка «крупный» с фактами и «малый»;
- `project_not_grilled` и `409`;
- новый `project.yaml` содержит `gates.grill: true`.
