# Доменная карта: разбор, состояние, предупреждения

Шаги: записи `map` с блоком `docdd-domain` — корректная, с битым JSON, со связью на неизвестный контекст, с контекстом `core` без словаря, с агрегатом без инвариантов. Проект с кодом без карты и проект без кода и без карты, с непокрытой возможностью `must`, с модулем вне корней.

Ожидаемый результат: корректная складывается в состояние, битая даёт ошибку разбора. `domain_map_missing`, `domain_capability_uncovered`, `domain_module_orphan`, `domain_relation_unknown`, `domain_language_empty`, `domain_aggregate_no_invariants` — каждое на своём случае (`domain_map_missing` только у проекта с кодом); вид `domain` в реестре второй после `functional`, шаг чек-листа `domain` идёт за `vision`; на чистом проекте ни одного.
