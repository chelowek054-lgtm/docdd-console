# Правила допроса: рекомендации, факты, понимание

Шаги:
- ход с `recommended`, `depends` и `facts`, ход без них, ход с неверными типами;
- ответ «Да» на вопрос с рекомендацией;
- конец с `understanding`, затем «Верно» и «Не так»;
- раскладка сессии в `confirm`.

Ожидаемый результат: верные поля принимаются, неверные отвергаются. «Да» пишет рекомендацию дословно. «Верно» закрывает сессию, «Не так» даёт раунд. Раскладка до «Верно» отказывает с причиной. В заметке есть разделы «Найдено в проекте» и «Общее понимание».
