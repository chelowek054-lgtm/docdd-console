# Проверка чата и ролевых шаблонов

На DocDD по адресу 127.0.0.1:3000 открыть чат из группы «Работа» и из глобального поиска. Сменить роль шапки между разработчиком, архитектором и наблюдателем. Проверить начальный шаблон, ручное переключение и неизменность прав доступа. Провести два хода по одной задаче, сверить использованные записи и повторное использование контекста. Проверить отмену и повтор после ошибки.
