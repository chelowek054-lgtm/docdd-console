# Записи карт: ждущие наверху, группы свёрнуты

Шаги:
- собранная консоль, временный проект: одна запись `map` в `draft`, несколько подтверждённых, одна `superseded`;
- открыть «Карты»;
- раскрыть «Подтверждены» и обновить страницу;
- подтвердить черновик и обновить страницу.

Ожидаемый результат:
- карточка раскрыта, первой идёт «Ждут подтверждения» с черновиком;
- «Подтверждены (N)» и «Вне суммы (N)» свёрнуты;
- после обновления «Подтверждены» остаётся раскрытой, «Вне суммы» — свёрнутой;
- без ждущих карточка свёрнута.
