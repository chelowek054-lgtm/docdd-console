# Разбор, сложение и проверки токенов дизайна

Модульные тесты `tests/design.spec.ts`: разбор блока `docdd-design` (неизвестные поля сохраняются, ошибка формата называется, а не роняет разбор); сложение «общее → локальное» с указанием источника у каждой части и `design_conflict` при противоречии; контраст по WCAG на парах эталона PRAXIS (все ≥ 4.5:1) и на нарочно плохой паре (< 4.5:1 → `design_contrast_low`); роль только в одной теме → `design_theme_incomplete`; нет `body` в шкале → `design_scale_gap`.
