# Отметить по фактам: предложение, черновик, подтверждение

## Предусловия

- Есть возможность, все задачи которой закрыты, а отметка «Не реализовано» или не оценена; у одной такой возможности все проверки пройдены, у другой проверка не запускалась.

## Шаги

1. Открыть «Стратегию» — видна строка «Отметки отстали от фактов» с числом отставших.
2. «Отметить по фактам» — у первой возможности предложено «Реализовано», у второй «Частично», у каждой причина.
3. Снять одну галочку, «Завести черновик» — заведена одна запись `map` в `draft` только с выбранными возможностями; отметки на экране пока прежние.
4. Подтвердить черновик — предупреждения `capability_behind` по выбранным возможностям пропали, число в строке уменьшилось.

## Ожидаемый результат

Отметка меняется только подтверждением черновика; без отставших строки нет. Автотест: `behindProposals` предлагает отметку по проверкам.
