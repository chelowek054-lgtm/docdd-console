# Требования к качеству: схема и quality_unmeasured

Шаги: требования с каждым из семи `quality` и с чужим значением; к числовым — без проверки, с проверкой `unit`, с проверкой `metric`; к `security` — без проверки и с `manual`.

Ожидаемый результат: схема принимает семь значений и отвергает чужое. `quality_unmeasured` — у числового без `metric` (в том числе с одной `unit`) и у `security` без проверки; с нужной проверкой — тишина; черновик требования не напоминает.
