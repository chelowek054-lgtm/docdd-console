# Проверка обязательного контекста карт для LLM

Сверить цель, схему, действующую легенду и состояние всех базовых карт через экран и MCP. Для кодовой карты сверить опись и свидетельство импорта. Проверить запись без контекста, с чужой картой или проектом, с устаревшей ревизией и с актуальным контекстом. Сверить проверку черновика и сценарий ручной правки.
