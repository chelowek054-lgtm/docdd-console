Контракты разбираются по формату (OpenAPI, proto, JSON-схема), справки — из файлов зависимостей разных языков, термины — из документации; на проекте во временной папке шаги заводят черновики со ссылкой на источник, существующие термины не трогаются, повторный запуск ничего не задваивает, чек-лист подключения видит заведённое.

Запуск: `npm run test -- tests/contracts-import.spec.ts`.
