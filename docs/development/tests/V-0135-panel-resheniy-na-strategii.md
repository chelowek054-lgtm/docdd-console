# Панель решений архитектора на «Стратегии»

Шаги: собранная консоль, временный проект с доменной картой, требованием `quality: load` с проверкой-метрикой, решением `storage` подтверждённым и `scaling` черновиком. Открыть «Стратегию».

Ожидаемый результат: под доменной картой блок «Решения архитектора». `storage` — «решено» со ссылкой; `scaling` — «черновик ждёт архитектора»; `topology`, `transactions` — «нет решения», «нужно»; `integration`, `security`, `deployment` — «по желанию». Требование к нагрузке показано с проверкой-метрикой.
