# Запись через MCP без входа — только на localhost

Шаги: функция решения о записи на сочетаниях «вход есть / нет» × «localhost / внешний адрес» × «токен агента есть / нет».

Ожидаемый результат: без входа на localhost — запись; без входа на внешнем адресе — только чтение с причиной; со входом — только с токеном агента.
