# Аналитика и сроки на реальном проекте

## Предусловия

- Реальный проект с историей задач (например, videos); у части задач заданы `due` и `estimate`.

## Шаги

1. «Работа» и карточка задачи — видны срок, «просрочена» / «осталось N дней», факт и оценка.
2. Фаза — срок и прогноз окончания.
3. «Аналитика» — средние lead и cycle time по типам и ролям (человек и агент отдельно), время по статусам, точность
   оценок, пропускная способность по неделям, просрочки.
4. Экспорт CSV и JSON открывается во внешней таблице, числа совпадают с экраном.
5. Перевести задачу в работу — в журнале строка со временем.
6. `npm run check` и «Обзор» показывают `task_overdue` у просроченной задачи; сборка не падает.

## Ожидаемый результат

Все шаги сходятся; старые строки журнала без времени не ломают расчёт.
