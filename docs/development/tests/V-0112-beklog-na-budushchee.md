# Бэклог: переходы deferred, исключение из текущей картины, вкладка и пачка

## Шаги

1. Подтверждённое требование → «В бэклог» с причиной: статус `deferred`, строка журнала, тело не изменилось. Черновик
   требования — отказ. «Вернуть в работу» — снова `approved` без нового подтверждения.
2. Задача из `backlog` и из `ready` → `deferred`; из `in_progress` — отказ; обратно — в `backlog`.
3. Отложенное не видно на «Задачах» и «Требованиях» (там число со ссылкой), не считается в готовности фаз, не даёт
   `requirement_unimplemented`/`requirement_unverified`, не предлагается в `implements`; задача с отложенным
   требованием не уходит в `ready`.
4. Вкладка «Бэклог» показывает отложенные требования, задачи и возможности с горизонтом «Потом»; пачка «В бэклог» и
   «Вернуть в работу» работают с одной причиной.
5. Ссылки на отложенную запись рабочие, поиск её находит.

## Ожидаемый результат

Все шаги сходятся; проверка проекта без новых ошибок; автотесты на переходы и исключение из правил зелёные.
