# HTML-макеты экранов: импорт, пути, цвета вне токенов, правила

Автотесты: раскладка HTML и zip под `mockups/<экран>/` — с отказом на `..`, абсолютные пути и превышение лимита;
черновик `design` с `screen` и `mockup`; повторный импорт черновика — новая версия и строка журнала,
подтверждённого — отказ; извлечение цветов из HTML и CSS (hex, rgb, hsl, css-переменные) и сравнение с токенами; правила
`mockup_screen_unknown`, `mockup_off_tokens`, `screen_mockup_missing` — предупреждения; маршрут отдачи
файлов макета не выходит за `mockups/<экран>/`.
