# Допрос функционала: поле grill, предупреждение и ворота

Шаги:
- раскладка сессии `feature` на подставной модели;
- задачи `change: feature` с `grill` у себя, у требования и без него;
- задача `change: fix` без `grill`;
- перевод в `ready` с `gates.grill` и без, одиночный и массовый.

Ожидаемый результат:
- заведённые записи несут `grill`;
- `feature_not_grilled` только у задачи-функции без следа;
- с воротами — `409` с причиной в обоих путях, без ворот — переход проходит;
- задача-починка не затронута.
