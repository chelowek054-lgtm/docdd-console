Тестовые файлы находятся и получают команду запуска по раннеру проекта; сопоставление с требованиями — по номеру в имени или начале файла и по словам пути, неоднозначное не угадывается; проверки заводятся черновиками без дублей; покрытие требований видно сразу. На проекте во временной папке отчёт сборки (JUnit-XML или JSON vitest/jest) подключается, итоги ложатся на проверки по файлам их команд, выход за корень отклоняется.

Запуск: `npm run test -- tests/test-checks.spec.ts`.
