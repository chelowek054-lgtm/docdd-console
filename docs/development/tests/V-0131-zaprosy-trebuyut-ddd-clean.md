# Запросы модели требуют DDD + Clean

Шаги: собрать запросы задачи, раскладки допроса, разбора входящих и аудита на временном проекте с доменной картой. Раскладка допроса на подставной модели.

Ожидаемый результат: в запросах есть указания про контекст и слой, про `domain` без фреймворков, про инварианты в сущности и корне, неизменяемые объекты-значения, политики и словарь, про варианты без выбора для решений архитектора. Раскладка даёт черновики `domain` и `decision` с `area`.
