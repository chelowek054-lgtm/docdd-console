# Запросы и справка System Design

Шаги: собрать запросы раскладки допроса, разбора входящих, задачи и аудита; раскладка допроса на подставной модели; открыть справку.

Ожидаемый результат: запросы несут указания про `quality`, проверки-метрики, варианты по областям с поводом, `against_decision`; раскладка даёт требование с `quality`, проверку `metric` и решение с `area` и «Вариантами»; в справке раздел «System Design в DocDD».
