# Визуальное редактирование карт

В редакторе выделить два узла рамкой, открыть «Создать группу», задать имя и описание. Провести связь портами, выбрать направление и обозначение. Проверить diff, отмену и сохранение через черновик. Повторить в полном экране и на обычной странице. Проверить отсутствие кнопки редактирования у наблюдателя и отказ API при прямом вызове. В просмотре проверить путь, глубину и неподвижность графа при выборе.
