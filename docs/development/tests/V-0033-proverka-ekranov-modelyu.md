# Проверка экранов моделью — Responsive и Pixel-Perfect

Ручная проверка на `learning`: снять экраны на 375/768/1280 в обеих темах; запустить проверку — по каждому экрану есть итог Responsive и Pixel-Perfect; затем в одном экране нарочно поставить свой цвет вместо `accent` и отступ 13 px вместо шкалы, а в другом — ширину, дающую горизонтальный скролл на 375: все три находки названы с экраном, шириной и темой. Плюс модульные тесты `tests/design-screens.spec.ts` на разбор ответа модели в находки и сборку запроса.
