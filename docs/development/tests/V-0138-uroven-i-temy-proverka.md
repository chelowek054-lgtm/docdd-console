# Уровни и обязательные темы

Шаги:
- шесть сочетаний вида и уровня;
- завершение при незакрытой обязательной теме;
- повышение и понижение уровня;
- записи сессии: с решением `area`; с четырьмя задачами; с одной правкой;
- старая сессия без `kind`;
- тест таблицы против `docs/08-usage.md`.

Ожидаемый результат:
- темы по таблице A-0006;
- завершение не проходит;
- повышение добавляет темы, понижение ниже границы запрещено;
- `grill_scope_low` у малой сессии с `area` (называет решение) и у малой с четырьмя задачами; молчит у малой с одной правкой;
- старая сессия читается со всеми темами;
- тест таблицы зелёный.
