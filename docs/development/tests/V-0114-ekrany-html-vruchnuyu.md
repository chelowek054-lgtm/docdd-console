# Вкладка «Экраны»: HTML из Claude Design вживую

## Шаги

1. Экспортировать экран из Claude Design (HTML или zip), на вкладке «Экраны» — «Добавить экран», выбрать экран карты путей.
2. Экран в списке — «черновик»; макет открывается живым, переключение 375/768/1280 и светлой/тёмной темы работает; скрипты
   макета не видят консоль (нет доступа к её cookie и API).
3. Рядом — снимок реализации той же ширины и темы, если он есть.
4. Подтвердить документ макета — задача с `documents` на него уходит в `ready`; до подтверждения — нет.
5. Цвет вне токенов в макете — предупреждение `mockup_off_tokens` в «Обзоре» и `npm run check`.

## Ожидаемый результат

Все шаги сходятся; файлы макета лежат только под `docs/development/design/mockups/<экран>/`.
