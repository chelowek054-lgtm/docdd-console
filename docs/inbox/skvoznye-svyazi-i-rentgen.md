# Сквозные связи через уровни и режим «Рентген»

Жёсткая иерархия «родитель → ребёнок → внук» в жизни нарушается: нижний компонент напрямую зовёт глобальное хранилище, логгер или шину событий, минуя слои; мелкая функция напрямую влияет на контур верхнего уровня. Если рисовать такие связи обычными линиями, карта превращается в лапшу.

- Связь между узлами разной глубины (не родитель–ребёнок) по умолчанию **скрыта**: чистая иерархия.
- При выборе узла все его сквозные связи подсвечиваются пунктиром другого цвета, с подписью «минует уровни …».
- Правило проекта может запрещать такие связи (как слои и модули с публичным входом, ADR-0013, для кода) — тогда это нарушение валидатора с кодом и советом вынести прослойку.
- Работает на функциональной карте, кодовой базе и своих картах одинаково.
