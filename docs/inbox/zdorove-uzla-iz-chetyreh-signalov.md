# Здоровье узла карты — только вычисляемое, из четырёх сигналов

Светофор узла (контура, возможности) не ставится руками и не учитывает бюджет. Ручной светофор устаревает на второй день, бюджет тянет консоль в учётную систему.

Сигналы — из того, что уже есть в проекте:

1. **Прогресс** — по состоянию возможностей-листьев («реализовано / частично / не реализовано / не оценено»), как считает `progressOf`. Не «% закрытых задач»: задачи разного размера, а закрытая задача ещё не даёт возможности.
2. **Сроки** — даты фаз, к которым привязаны задачи узла; просрочка.
3. **Качество** — упавшие автопроверки и ручные проверки, ждущие приёмки, по требованиям узла.
4. **Нарушения** — ошибки и предупреждения валидатора по записям, связанным с узлом.

Состояние узла — худшее из сигналов (в норме / внимание / проблема / заблокирован), сворачивается снизу вверх до контура. Рядом — причина: какой сигнал и где, ссылкой туда, где проблема.
