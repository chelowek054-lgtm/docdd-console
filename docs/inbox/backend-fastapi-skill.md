# Бэкенд: FastAPI + чистая архитектура + DI

Заменяет A-0002 (та же практика, в skill-формате вместо эссе): заведи
decision с `supersedes: [A-0002]`.

Когда: заводишь или правишь серверную часть проекта на Python.

## Делай

- FastAPI — веб-фреймворк по умолчанию.
- SQLAlchemy (async) — доступ к базе; модели и запросы не смешивай с
  обработчиками HTTP-запросов напрямую.
- Держи слой домена (бизнес-правила) не знающим о FastAPI, SQLAlchemy или
  HTTP вообще — эти правила вызывает слой инфраструктуры.
- Собирай зависимости через DI-контейнер (например, Dishka) — обработчик
  запроса получает готовые сервисы через инъекцию, а не строит их сам.
- PostgreSQL — база по умолчанию, если нет причины для другой.

## Не делай

- Не обращайся к базе прямо из обработчика HTTP-запроса, минуя слой
  домена/сервисов.
- Не клади секреты и ключи внешних провайдеров куда-либо, кроме бэкенда.
