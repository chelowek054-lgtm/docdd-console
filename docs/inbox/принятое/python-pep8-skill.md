# Python: PEP 8

Заменяет A-0006 (та же практика, в skill-формате вместо эссе): заведи
decision с `supersedes: [A-0006]`.

Когда: пишешь Python-код в этом стеке.

## Делай

- 4 пробела на уровень отступа, без табов.
- Длина строки — по умолчанию PEP 8 (79 знаков), если проект явно не
  договорился о своём пределе.
- Имена: `snake_case` для функций и переменных, `PascalCase` для классов,
  `UPPER_SNAKE_CASE` для констант, ведущее подчёркивание — «не для
  внешнего использования».
- Импорты отдельными строками, сгруппированы (стандартная библиотека →
  сторонние → локальные), без `import *`.
- `is`/`is not` для сравнения с `None`, `isinstance()` вместо сравнения
  типов напрямую.
- Docstring — для каждого публичного модуля, класса, функции.
- Форматирование и порядок — автоматически линтером (`ruff`/`black`), не
  вычитыванием глазами.

## Не делай

- Не жертвуй читаемостью ради буквального соответствия — сам PEP 8
  разрешает «знать, когда быть непоследовательным».
- Не переформатируй существующий код ради формы без причины.
