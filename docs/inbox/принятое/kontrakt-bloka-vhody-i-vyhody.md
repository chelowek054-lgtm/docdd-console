# Контракт блока: входы и выходы узла

У узла карты (контур, возможность, модуль, узел своей карты) — явные границы:

- **Входы** — какие документы, контракты, данные или результаты других блоков нужны, чтобы блок начал работу.
- **Выходы** — что блок производит: работающий модуль, контракт API, данные, экран.

Правило: работа по блоку не стартует, пока его входы не подтверждены — тот же принцип «документ ведёт код», только на уровне блока. Выход одного блока — вход другого, это и есть связь `feeds`. На этом строится карта архитектора «модули входных и выходных данных».
