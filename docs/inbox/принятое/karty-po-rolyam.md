# Карты по ролям: у каждой роли своя

Каждая роль может создать карту под свои цели — на механизме своих карт (ADR-0028), со связями в стратегический уровень:

- **Дизайнер** — полный желаемый UserFlow: как должно быть (план), с наложением реализованного по коду. Сейчас пути строятся только по коду.
- **DevOps** — инфраструктурная карта: окружения, сервисы, хранилища, сети, связь с релизами.
- **Архитектор** — модули как блоки с входами и выходами (см. заметку о контракте блока).
- **Разработчик** — взаимосвязь компонентов фронтенда и бэкенда **внутри каждого модуля** отдельно, потом общая карта взаимодействия модулей в системе. Бесконечная вложенность (ADR-0027) позволяет раскрыть модуль в свою карту.

Заготовки этих карт входят в шаблон проекта `software-core`.
