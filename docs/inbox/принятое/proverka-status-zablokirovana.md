# Итог прогона «заблокирована»: не могу проверить, мешает X

В инструментах тестирования стандартны итоги «прошла / провалена / заблокирована / пропущена». У нас нет «заблокирована» — тестировщик вынужден ставить «пропущена» и теряет причину.

- Новый итог прогона `blocked` в отчёте (`tests/reports`), с обязательной причиной: текст и, по возможности, ссылка на мешающую запись (задачу, дефект).
- На «Сверке» — плашка факта «Заблокированы» между «Провалены» и «Ждут ручной приёмки»; в «Прогоне» — выбор «заблокирована» с полем причины.
- Заблокированная проверка не считается ни пройденной, ни проваленной; в здоровье узла карты — сигнал «внимание».
- Снимается следующим прогоном с другим итогом.
- Контракт отчёта (docs/02-workspace-contract.md) расширяется новым значением — незнакомое значение старые инструменты должны сохранять.
