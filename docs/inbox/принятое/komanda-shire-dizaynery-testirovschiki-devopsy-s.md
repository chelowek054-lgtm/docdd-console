# Команда шире: дизайнеры, тестировщики, девопсы, сопровождение

Вектор называет шесть ролей. Для серверного режима полноценной команды нужны роли designer, qa, devops, support со своими правами в матрице и рабочими местами; вектор (аудитория) расширяется. Без фаз 25–26 (безопасность, вход, права) команду на сервер не пускаем — они первые.
