# Скорость отрисовки: ответ карты отдаёт все виды сразу и ложится в каждую загрузку /maps

GET /api/projects/:id/map — 266 КБ: кодовая база, потоки данных, пути, пользовательские и функциональная карта вместе, плюс история. Страница карт берёт его useFetch при отрисовке на сервере, и весь ответ встраивается в HTML (payload 258 КБ), даже когда открыта одна вкладка.

Предложение: на сервере рисовать только открытую вкладку — ответ по виду (?kind=functional|codebase|flows|journeys|custom) или отдельные запросы, остальные виды догружать при переключении вкладки и держать в памяти страницы. Сводки для вкладок (числа на ярлыках) — отдельным лёгким полем. Цель: payload /maps < 120 КБ на функциональной вкладке.
