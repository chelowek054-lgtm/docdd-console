# Связи между картами: ролевые карты входят в стратегию ссылками

Сейчас карты живут каждая сама по себе: функциональная, кодовая база, потоки данных, пользовательские пути, свои карты (ADR-0028). Нужна ссылка из узла одной карты на узел другой.

- Возможность функциональной карты ссылается на модули кодовой базы, пути дизайнера, узлы инфраструктурной карты и т. п.
- Обратная сторона видна: у модуля или экрана — «реализует возможность …».
- Прогресс и здоровье по-прежнему считает функциональная карта; связанные узлы — свидетельства и путь для проваливания.
- Ссылка на несуществующий узел — нарушение валидатора, как висящая связь записи.

Это и есть «остальные фичи проекта входят в стратегию ссылками».
