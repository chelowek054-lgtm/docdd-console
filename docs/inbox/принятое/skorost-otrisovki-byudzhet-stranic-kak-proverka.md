# Скорость отрисовки: бюджет страниц как проверка-метрика

Регрессии скорости сейчас видны только на глаз: функциональная карта выросла до 2,6 с, и никто этого не заметил. Нужна проверка-метрика: скрипт открывает ключевые страницы проекта-образца (обзор, работа, карты по вкладкам, карточка записи, проверки, дизайн) и пишет в отчёт tests/reports время первого байта, размер HTML и payload, число узлов DOM; превышение бюджета — failed по своей проверке V-…. Бюджеты — из заметок про карту, ответ карты, списки и индекс.
