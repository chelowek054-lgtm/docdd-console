# JavaScript и TypeScript: линт — ESLint, а не JSLint

Заменяет A-0007 (та же практика, в skill-формате вместо эссе): заведи
decision с `supersedes: [A-0007]`.

Когда: настраиваешь линтер для JS/TS-проекта в этом стеке.

## Делай

- Настраивай ESLint — не JSLint (не расширяется правилами под проект).
  Дух правил JSLint разумен и взят за основу, расходится только инструмент.
- Требуй только `===`/`!==` (кроме осознанного `== null`, ловящего и
  `undefined`).
- `const` по умолчанию, `let` — когда переменная правда переприсваивается,
  `var` — никогда.
- Точка с запятой обязательна — не полагайся на автоматическую
  расстановку.
- Неиспользуемая или дважды объявленная переменная — ошибка, не
  предупреждение.
- Блоки `if`/`while`/`for` — всегда в фигурных скобках, даже из одной
  строки.

## Не делай

- Не запрещай то, что JSLint запрещает категорично без замены (например,
  побитовые операторы), если это правда нужно для задачи (маски,
  бит-флаги).
