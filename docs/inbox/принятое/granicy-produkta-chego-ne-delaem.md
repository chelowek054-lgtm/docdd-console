# Границы продукта: чего консоль не делает (дополнить вектор)

По итогам разбора сценариев развития — в «Чего продукт не делает»:

- Сферы вне IT: заводы, стройка, продажи, логистика. Консоль — для разработки ПО, где есть код, git, тесты и модели.
- Бюджет, CAPEX и OPEX, учёт ресурсов — это ERP.
- Опрос внешних систем (Jira, GitHub, ERP) из узлов карты: файлы проекта — правда (ADR-0001); перенос из Jira и Confluence — импортом.
- Собственные жизненные циклы, статусы и переходы под сферу: контракт `docdd.workspace/1` один для всех.
- Провайдеры бинарных свидетельств (`.step`, `.gbr`, `.uasset`) — не сейчас. Заложить только поле «вид» у свидетельства, чтобы потом не менять формат.
