# Девопс и сопровождение: релизы, окружения, Grafana

Релизы и окружения: какие задачи ушли в какую версию и где выложены. Grafana: консоль отдаёт метрики процесса для Prometheus; алерт Grafana приходит заметкой во входящее (инцидент для сопровождения); проверка-метрика берёт значение запросом Prometheus с порогом; у возможности — ссылки на панели. Своей базы метрик консоль не заводит.
