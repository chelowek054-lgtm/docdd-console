# Скорость отрисовки: режим разработки на каждый день

Полная загрузка любой страницы в режиме nuxt dev — 241 отдельный модуль JS (Vite отдаёт несобранным), это добавляет сотни миллисекунд при каждом F5 независимо от страницы. Консоль ежедневно используется именно так.

Предложение: команда для ежедневной работы на собранной версии (nuxt build + запуск .output) и упоминание в README/08-usage, режим разработки — для правки самой консоли. Решает человек: меняется привычный способ запуска.
