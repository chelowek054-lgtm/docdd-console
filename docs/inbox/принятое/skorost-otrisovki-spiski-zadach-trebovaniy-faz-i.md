# Скорость отрисовки: списки задач, требований, фаз и проверок на переходе

Замер переходов внутри приложения (длинная задача главного потока при открытии):
- /work (98 задач, 1850 узлов DOM) — 0,29 с;
- /checks — 0,20 с; /phases — 0,16 с; /requirements — 0,14 с; /documents — 0,13 с.

Каждая строка — несколько UBadge и UCheckbox Nuxt UI; на /work ещё сортировка, факт проверки и ревьюер на каждую строку (reviewerOf ищет проверки перебором всех записей для каждой задачи). Списки уже режутся порциями (useChunked), но порция рисуется целиком тяжёлыми компонентами.

Предложение: лёгкие метки (span с классом из общей таблицы цветов вместо UBadge в строках), производные по строкам считать один раз картой по id (проверки задачи — из обратных связей индекса, а не перебором), первая порция меньше. Цель: длинная задача при переходе < 100 мс на каждом из этих экранов.
