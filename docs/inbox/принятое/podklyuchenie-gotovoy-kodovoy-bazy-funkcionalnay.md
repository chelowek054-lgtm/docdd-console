# Подключение готовой кодовой базы: функциональная карта и требования «как есть»

Для готовой кодовой базы нужно восстановить «как есть»: после импорта документации и построения карт кода, потоков и путей модель по картам и документам предлагает возможности функциональной карты с состоянием «реализовано» и свидетельством в коде, затем требования «как есть» под реализованные возможности — черновиками. Это базовая линия, дальше работа идёт обычным кругом DocDD.
