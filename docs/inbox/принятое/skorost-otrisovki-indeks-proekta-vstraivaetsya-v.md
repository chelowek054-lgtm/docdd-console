# Скорость отрисовки: индекс проекта встраивается в каждую страницу

useProjectIndex берёт /api/projects/:id/index (≈190 КБ: 223 записи с обратными связями и extra, 26 КБ нарушений) при отрисовке на сервере, поэтому индекс целиком встраивается в HTML каждой страницы проекта: /work 371 КБ, /design 261 КБ, карточка записи 182 КБ, даже где из индекса нужно меньше.

Предложение: не гонять индекс дважды (в HTML и в памяти клиента) — разделить лёгкий список записей (id, тип, статус, заголовок, связи) и тяжёлые части (нарушения, extra, обратные связи) по запросу; на страницах, где индекс второстепенный, — server: false. Цель: HTML карточки записи < 80 КБ, /work < 200 КБ.
