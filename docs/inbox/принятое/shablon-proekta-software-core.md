# Шаблоны проекта: сначала software-core

Шаблон проекта — **данные, а не движок**: набор контуров стратегического уровня, заготовки своих карт по ролям, роли команды и подключённые практики. Ядро (типы записей, статусы, переходы, правила) шаблон не меняет.

Порядок:

1. `software-core` — веб, бэкенд, фулстек. Сейчас, полностью: контуры (Продукт и требования, Архитектура и код, Интерфейс и дизайн, Инфраструктура и выкладка, Качество и безопасность, Выпуск и поддержка), карты по ролям, роли.
2. `gamedev` — третьим: игровые системы, сцены и ассеты, таблицы баланса и их схемы.
3. `llm-product` — когда появится проект, чей продукт — система на LLM (промпты, датасеты, оценки как артефакты продукта). Не раньше.

Отдельного шаблона «ai-agentic-dev» не делаем: агенты ролей — возможность консоли для любого проекта (см. заметку об агентах ролей), а контроль над кодом от моделей — вектор самой консоли, а не тип проекта.

Шаблон выбирается при подключении нового проекта; без модели получается базовый каркас из шаблона.
