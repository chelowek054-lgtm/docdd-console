# Фронтенд: Nuxt 4 + TypeScript + Feature-Sliced Design

Заменяет A-0001 (та же практика, в skill-формате вместо эссе): заведи
decision с `supersedes: [A-0001]`.

Когда: заводишь или правишь клиентскую часть проекта на этом стеке.

## Делай

- Nuxt 4 + TypeScript — базовый стек клиента, не JavaScript и не более
  ранняя версия Nuxt без явной причины.
- Feature-Sliced Design (FSD): слои `app / pages / widgets / features /
  entities / shared`, зависимости только вниз по слоям. Доменно-независимое
  переиспользуемое ядро — в `shared`.
- Nuxt UI как базовая библиотека компонентов, если для проекта явно не
  решено иначе.
- Подключай i18n сразу, если в плане есть хоть один нерусскоязычный
  пользователь — заводить его задним числом дороже.

## Не делай

- Не мешай слои FSD как попало — `features` не лезет напрямую в `entities`
  другого домена, только через публичный интерфейс слоя.
- Не заводи свою структуру папок «для особого случая» без записанного
  решения, почему стандартная не подошла.
