# Подключение проекта: дополнения к готовым задачам T-0139…T-0144

Сценарии «готовая кодовая база» и «новый проект» уже разобраны (M-0058). Дописать:

- **Git обязателен**: при указании пути проверяется репозиторий; нет — консоль предлагает `git init` с ветки `main`, только с согласия человека.
- **Модель необязательна**: без неё — базовый каркас из шаблона проекта (заготовки контуров и карт, пустые записи); с ней — разбор пачками, предложения списком, подтверждение человеком. Записи процесса модель сама не пишет.
- **Выбор шаблона проекта** при создании нового (см. заметку о шаблонах).
- **Дописать проверки V-0075…V-0080.** Сейчас это пустые заготовки: заведены видом «модульный тест», но без `command` и без шагов — карточка проверки честно пишет, что их нечем запускать. Когда берутся задачи T-0139…T-0144: у каждой проверки — файл теста и `runner`/`command`, либо вид `manual` с предусловиями, шагами и ожидаемым результатом.
- **Обучение новым пользователям** после подключения: как читать стратегию и карты, почему задача не уходит в работу без документа, как работать с моделью через ветку и дифф. Кнопка «Пропустить», пройденное помнится.
