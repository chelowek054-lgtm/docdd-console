# Подключение: автопоиск источников и тупик импорта

При заведении sources.code, docs, client пусты, и экран «Импорт» упирается в тупик «не объявлено sources.docs» без кнопки. Нужно: автопоиск источников — папки кода, клиента, документации, тестов; файлы OpenAPI, proto, JSON-схем; файл зависимостей; отчёты CI — с предложением человеку подтвердить; на экране «Импорт» — указать папки sources.docs прямо там, с найденными автоматически вариантами, запись в project.yaml через приложение.
