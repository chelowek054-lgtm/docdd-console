# Подключение: проверки из существующих тестов и отчёт сборки

Существующие тесты не превращаются в проверки. Нужно: найти тестовые файлы, сопоставить их с требованиями (по путям, именам, свидетельствам карты кода), завести проверки вида unit/integration с командой запуска, подключить отчёт сборки (формат раннера) — сразу видно, что реально покрыто.
