# Подключение проекта: чек-лист готовности и одна точка входа

Сейчас заведение проекта даёт почти пустой каркас, а пути наполнения разбросаны по пяти экранам (импорт, карты, входящее, справочник, дизайн), и их порядок человек должен знать заранее. Нужна одна точка входа: карточка «Готовность проекта» на Обзоре — чек-лист шагов со статусом (не начато / готово / ждёт подтверждения), вкладка «Подключение» в группе «Наполнение», выбор сценария при заведении на главной («Новый проект» или «Готовая кодовая база»). Кнопка «Запустить подключение» выполняет автоматические шаги и ставит в очередь шаги с моделью. Каждый шаг перезапускаемый, ничего не перетирает и даёт только черновики; приём — пачками через «Приём изменений». Одна кнопка, молча строящая всё, противоречит правилу «модель не подтверждает за человека».
