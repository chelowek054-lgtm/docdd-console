# Скорость отрисовки: функциональная карта рисует кнопки наведения у каждой строки

Замер 2026-10-20 (режим разработки, проект docdd-console, 119 возможностей):

- /maps — первый байт 2,1–2,6 с, HTML 1,15 МБ, страница успокаивается через 4,3 с;
- после перехода внутри приложения — одна длинная задача 0,88 с (гидратация дерева);
- в разметке 755 кнопок, из них 497 одинаковых UButton с классом в 660 знаков: только атрибуты class — 514 КБ из 816 КБ разметки.

Причина: FunctionalTreeNode у каждой строки рисует четыре кнопки «по наведению» (подпункт, правка, связь, убрать; скрыты CSS hidden group-hover:flex), шеврон-UButton и UDropdownMenu с UButton состояния. 119 строк × 6 компонентов Nuxt UI, каждый со своим tailwind-variants.

Предложение: панель действий — одна на дерево, появляется у строки под курсором или в фокусе (клавиатура тоже); шеврон и состояние — лёгкие button со своими короткими классами; меню состояния создаётся по клику. Цель: /maps первый байт < 0,6 с, HTML < 350 КБ, длинная задача при переходе < 200 мс. Поведение и вид не меняются.
