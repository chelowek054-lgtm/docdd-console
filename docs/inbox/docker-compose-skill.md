# Локальная разработка: docker-compose база + override

Заменяет A-0003 (та же практика, в skill-формате вместо эссе): заведи
decision с `supersedes: [A-0003]`.

Когда: у проекта есть отдельный бэкенд и база, которые надо поднимать
локально.

## Делай

- `docker-compose.yaml` — базовый, прод-подобный стек:
  `docker compose -f docker-compose.yaml up --build`.
- `docker-compose.override.yaml` — оверрайд для локальной разработки:
  переключает сервисы на dev-цели с hot-reload, подхватывается
  автоматически обычным `docker compose up`.
- `.env.example` — шаблон переменных окружения в репозитории; настоящий
  `.env` — только локально, вне репозитория.
- Все значения конфигурации бери из `.env`, не зашивай в
  `docker-compose.yaml`.

## Не делай

- Не коммить настоящий `.env` с реальными значениями.
- Не заводи третий отдельный способ запуска «для тестов»/«для CI», если
  хватает override с другими значениями `.env`.
