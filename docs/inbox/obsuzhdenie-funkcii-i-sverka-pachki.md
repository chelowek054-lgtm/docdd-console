# Обсуждение будущей функции ролями и сверка пачки

Цель процесса: архитектор, аналитик, DevOps, дизайнер, тестировщик обсуждают новую функцию и складывают пожелания и требования во входящее; модель разбирает; дальше — **общая проверка логичности** требований, задач и тестов вместе.

- Обсуждение функции до появления записей: заметки с меткой роли, сгруппированные по функции; разбор берёт обсуждение целиком.
- **Сверка пачки**: одна сверка на функцию — противоречия между требованиями, задачи без требований, требования без проверок, тесты, которые не проверяют критерий. Отчёт противоречий; пока он не закрыт, задачи функции не переходят в `ready`.
- Затем задачи назначаются на людей или агентов; статусы задач и проверок двигают они (руками или через модель).
