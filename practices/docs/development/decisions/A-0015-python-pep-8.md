# Python: PEP 8

4 пробела на уровень отступа, без табов. Длина строки — по умолчанию PEP 8 (79 знаков), если проект явно не договорился о своём пределе. Имена: snake_case для функций и переменных, PascalCase для классов, UPPER_SNAKE_CASE для констант, ведущее подчёркивание — «не для внешнего использования». Импорты отдельными строками, сгруппированы (стандартная библиотека → сторонние → локальные), без import *. is/is not для сравнения с None, isinstance() вместо сравнения типов напрямую. Docstring — для каждого публичного модуля, класса, функции. Форматирование и порядок — автоматически линтером (ruff/black).

Не делать: не жертвовать читаемостью ради буквального соответствия; не переформатировать существующий код ради формы без причины.

Источник: PEP 8 — peps.python.org.
