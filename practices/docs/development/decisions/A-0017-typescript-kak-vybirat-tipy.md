# TypeScript: как выбирать типы

Аннотировать там, где вывод типов не справляется, — параметры функций, публичные возвращаемые значения. interface по умолчанию, type — для объединений, примитивов, условных типов. noImplicitAny включён всегда; any — временная заплатка с объяснением рядом. strictNullChecks включён всегда; null/undefined проверять сужением типа, не оператором !. Ограниченный набор значений — объединением («left» | «right» | «center»), не строкой без ограничений. as Type — редко и осознанно.

Не делать: не переусложнять типами то, что и так понятно из структуры; не использовать any, чтобы «заставить компилятор замолчать», без разбора, откуда несовпадение типов взялось на самом деле.

Источник: TypeScript Handbook.
