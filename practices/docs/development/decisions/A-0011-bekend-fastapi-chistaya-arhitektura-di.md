# Бэкенд: FastAPI + чистая архитектура + DI

FastAPI — веб-фреймворк по умолчанию для серверной части на Python. SQLAlchemy (async) для доступа к базе, не смешанный с обработчиками HTTP-запросов. Слой домена не знает о FastAPI/SQLAlchemy/HTTP — эти правила вызывает слой инфраструктуры. Зависимости собираются через DI-контейнер (например, Dishka): обработчик получает готовые сервисы инъекцией, а не строит их сам. PostgreSQL — база по умолчанию, если нет причины для другой.

Не делать: не обращаться к базе прямо из обработчика HTTP-запроса, минуя домен/сервисы; не класть секреты и ключи внешних провайдеров куда-либо, кроме бэкенда.

Источник: проверено на практике InteractMed.
