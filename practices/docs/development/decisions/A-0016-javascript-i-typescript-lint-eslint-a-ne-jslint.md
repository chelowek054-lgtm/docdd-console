# JavaScript и TypeScript: линт — ESLint, а не JSLint

Настраивать ESLint, не JSLint (не расширяется правилами под проект); дух правил JSLint взят за основу, расходится только инструмент. Требовать только ===/!== (кроме осознанного == null, ловящего и undefined). const по умолчанию, let — когда переменная правда переприсваивается, var — никогда. Точка с запятой обязательна. Неиспользуемая или дважды объявленная переменная — ошибка, не предупреждение. Блоки if/while/for — всегда в фигурных скобках.

Не делать: не запрещать то, что JSLint запрещает категорично без замены (например, побитовые операторы), если это правда нужно для задачи (маски, бит-флаги).

Источник: JSLint (jslint.com), ESLint (eslint.org).
