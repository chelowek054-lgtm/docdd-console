# Единый дизайн PRAXIS — токены для всех проектов консоли

Эталон оформления, который консоль спускает в проекты на Nuxt + Nuxt UI, React Native +
Expo, Kotlin/Compose и Swift/SwiftUI ([docs/16-design-system.md](../../../../../docs/16-design-system.md)).
Значения палитры не придуманы: перенесены из `learningFront/src/shared/config/design.ts` проекта
`learning`, где контраст уже проверен на фонах своей темы (приглушённый текст держит около 5:1).
Роли названы по смыслу, а не по оттенку: `accent`, а не `green`.

**Единица — rem** ([ADR-0023](../../../../../docs/adr/0023-adaptive-by-default.md)): размеры шкал
переведены из пикселей исходного конфига делением на 16 (15 px → 0.9375rem, 12 px → 0.75rem).
Начертания (`weight`) в исходном конфиге заданы словарём без привязки к кеглям; здесь привязка
выбрана так: текст — 400, `lead` — 500, `title` — 600, `display` — 700. Межстрочный интервал —
исходные 1.45 от кегля, округлённые до 1/16 rem. Сетка — Bootstrap 5 в rem: 12 колонок, поле
1.5rem, шесть точек перелома. Языки — русский основной и английский.
