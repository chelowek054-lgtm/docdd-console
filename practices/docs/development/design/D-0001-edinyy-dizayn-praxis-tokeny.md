# Единый дизайн PRAXIS — токены для всех проектов консоли

Эталон оформления, который консоль спускает в проекты на Nuxt + Nuxt UI, React Native +
Expo, Kotlin/Compose и Swift/SwiftUI ([docs/16-design-system.md](../../../../../docs/16-design-system.md)).
Палитра до v1.4.0 была перенесена из `learningFront/src/shared/config/design.ts` проекта `learning`; в v1.4.0 её
собрали заново, потому что зеленовато-серая основа с тёмным бирюзовым акцентом выглядела тусклой, а нейтральные
ступени расходились с холодной палитрой `neutral` библиотеки интерфейса. Первая замена (индиго) вышла слишком громкой,
поэтому в v1.5.0 акцент приглушён: синий средней светлоты, у больших заливок насыщенность около половины, яркие
оттенки оставлены малым элементам. Цвета смысла читаются на фоне и поверхности не ниже 4.5:1. Роли названы по смыслу,
а не по оттенку: `accent`, а не `blue`.

**Единица — rem** ([ADR-0023](../../../../../docs/adr/0023-adaptive-by-default.md)): размеры шкал
переведены из пикселей исходного конфига делением на 16 (15 px → 0.9375rem, 12 px → 0.75rem).
Начертания (`weight`) в исходном конфиге заданы словарём без привязки к кеглям; здесь привязка
выбрана так: текст — 400, `lead` — 500, `title` — 600, `display` — 700. Межстрочный интервал —
исходные 1.45 от кегля, округлённые до 1/16 rem. Сетка — Bootstrap 5 в rem: 12 колонок, поле
1.5rem, шесть точек перелома. Языки — русский основной и английский.

**Из практики** ([ADR-0024](../../../../../docs/adr/0024-design-from-practice.md)): принципы юзабилити — из «UX.txt»; шрифты (не больше трёх), длина строки 45–80 символов, толщины линий, размеры значков и движение — из «UX.txt» и «DisSys (2).txt»; видимый фокус и контрастная тема 7:1 — из «Ux2.txt» (WCAG 2.1 AA, высококонтрастный режим); состояния, слои и жизненный цикл компонентов — из «DisSys (2).txt».

**Цвет на реальных экранах** ([ADR-0026](../../../../../docs/adr/0026-color-on-real-screens.md)): палитра — в sRGB; тёмная тема в двух вариантах — `dark` (матовый тёмно-серый, по умолчанию) и `oled` (истинно чёрный фон для OLED-экранов); насыщенность больших заливок ниже 90 %; основной рынок — RU, продукт на улице не используется (`audience`).
