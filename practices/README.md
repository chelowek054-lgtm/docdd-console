# Встроенный набор практик

Обычный DocDD-проект внутри репозитория консоли: `decision` и `design` с лучшими
практиками (стиль кода, стек, архитектура) и блоками правил `docdd-rules`. Каждый
проект подключает его сразу по пути `builtin` в `sources.shared` — по умолчанию с
тегом `general`, остальные теги включаются на экране «Практики».

Подключённые записи уходят в запрос модели на выполнение задачи, в сверку кода с
практиками и в правила проверки архитектуры. Консоль читает набор только для
чтения; пополняется он тем же циклом, что любой проект: правка записи, показ,
подтверждение человеком. Подробнее —
[docs/11-shared-sources.md](../docs/11-shared-sources.md) и
[ADR-0015](../docs/adr/0015-builtin-practices.md).
